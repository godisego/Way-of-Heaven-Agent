# Security Policy · 安全政策

## Supported versions · 支持版本

Security fixes are currently provided for the latest `main` branch. This project is experimental; do not expose a local instance to the public internet without adding authentication, authorization, rate limiting, and secure secret management.

## Reporting a vulnerability · 报告漏洞

Do not open a public Issue for credentials, private data exposure, remote code execution, or other sensitive vulnerabilities. Please email **chikongmuzhi@gmail.com** with a concise description, reproduction steps, affected files, and potential impact. 中文报告同样欢迎。

Please do not include API keys, birth information, uploaded documents, or other personal data in the report. We will acknowledge receipt when possible and coordinate a fix or disclosure timeline with the reporter.
