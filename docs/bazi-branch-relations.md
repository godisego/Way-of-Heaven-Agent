# 天干五合与地支合冲刑害会：从单字到字间关系

排盘只数八个字的天干地支，远远不够。两个字相邻或对位时，会发生**合、冲、刑、害、会**等关系——它们决定原局力量是联结、对撞、消耗还是被引动。可以把单字看成独立的服务器节点，字间关系看成节点之间的网络拓扑：同一组节点，连法不同，系统行为完全不同。

速查入口：[天干](/learn#mingli-tiangan) · [地支](/learn#mingli-dizhi) · [藏干](/learn#mingli-canggan) · [十神](/learn#mingli-shishen) · [月令](/learn#mingli-yueling)。

## 一 · 为什么要看字间关系

| 关系 | 作用方向 | 一句话记忆 | 软件比喻 |
| --- | --- | --- | --- |
| 合 | 联结 / 转化 | 两字或多字结成一股合力，可能改五行 | 服务间建立连接，可能改变数据流向 |
| 冲 | 对撞 / 拆开 | 位置正对、五行相克、方向相反 | 节点对位冲突，原有结构被冲散或激活 |
| 刑 | 牵制 / 反复 | 结构内部不顺，内耗与反复 | 模块循环依赖，配合中反复牵制 |
| 害（穿） | 隐损 / 不和 | 表面无冲突，配合时却互相损耗 | 接口签名兼容，运行时却暗耗资源 |
| 会（三会） | 同类聚集 | 多字相邻形成同类大环境 | 同机房服务器组成集群 |
| 三合 | 远联结成局 | 三字定方向、中字为局神 | 跨节点形成协同管道，方向一致 |

关键认知：**单字的力量是出厂参数，字间关系是运行时拓扑**。同一组八字，原局有合与无合、有冲与无冲，断命结论差别极大。

## 二 · 天干五合

甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火。

```tianganhe
```

**合化不是看到一对就化**。子平通行口径要求同时满足：

1. **相邻**：两干在年月、月日或日时之间；隔柱则合力弱。
2. **化神有根**：化神五行在月令或周边地支有根气支持。
3. **不被克破**：没有其他天干地支明显克制化神或合干之一。

举例：示例盘 **乙丑年　戊寅月　甲子日　丙寅时**。年干乙、时干丙——既不是乙庚合也不是丙辛合，本盘无天干合。若把时柱改为癸酉时，则月戊时癸相邻，戊癸合火——但月令寅木当令、火气未旺（要巳午未月才有火根），合火通常不化，称"合而不化"。两干仍互相牵绊，但原五行不改。

**合而不化的意义**：被合的两干各自"分心"，原本要去做的事（生克日主、生克其他字）被另一合干牵扯，力量打折。

## 三 · 地支六合

子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合（午未合流派不一，有合化火、合化土、合而不化三说）。

```liuhe
```

六合发生在相邻两支之间。判断次序：

1. **真成合**：两支都在原局或大运流年中可见，且中间不被同位冲破。
2. **化神呼应**：化神在月令或周边地支有气。
3. **盖头截脚**：同柱天干是否克地支（如子水被同柱戊土盖头）。
4. **是否被三合/三会抢**：若同时是三合局一字，三合优先。

举例：示例盘地支 **丑　寅　子　寅**。日支子无丑配对（年支才是丑，可与日支子论合，但年日远隔、合力弱）。若时支改丑（丙丑时），子丑相邻，子丑合土——再看月令寅木克土、土气失令，通常合而不化。但合的关系仍成立，子水被丑土牵扯，丑土被子水牵扯，互相减力。

**六合不化的常见误用**：看到子丑就宣布"水变土"。是否化要核对化神根气，缺根气就只是"合绊"——两个字互相牵制、力量打折，五行不改。

## 四 · 地支三合局

申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。

```sanhe
```

三合的特点：

- 三字齐全才成**局**，缺一字叫**半合**（如申子半合水、子辰半合水）。
- **中字为局神**，力量集中：申子辰中的子、亥卯未中的卯、寅午戌中的午、巳酉丑中的酉。
- 三合成局后，会显著放大该五行气势，能压过单字与六合。

举例：示例盘地支 **丑　寅　子　寅**。无申、无辰，子水单见，三合水局不成立。但子是水局的中字——若大运或流年遇申或辰，且不被冲克，可半合成水局，日主甲木的印星气势突增（水生木），是观察"印星被引动"的窗口。

**半合的判断**：申子半合（缺辰）与子辰半合（缺申）都成立但力量弱于全合。子辰半合尤其常见——子水本旺，再得辰库，水库大开。

## 五 · 地支三会局

寅卯辰会木方、巳午未会火方、申酉戌会金方、亥子丑会水方。

```sanhui
```

三会比三合更"硬"——三字**齐全且位置相邻**才成会局，一旦成局，本方五行极旺。三会成立条件更严，但成立时通常力量大过三合。

举例：示例盘地支 **丑　寅　子　寅**。无寅卯辰三字齐全（只一个寅），三会木方不成立。但若大运逢卯、流年逢辰（且无申酉金冲克），原局+岁运可能短暂形成木方会局，日主比劫力量突增——传统多读为"朋辈、竞争、自主"主题被引动。

**三会 vs 三合的实战取舍**：原局有三会者，气势偏一方极旺，喜忌要顺这股气势走，不能再按平均五行判断。原局有三合者，方向明确但力量温和，可被引动也可被破。

## 六 · 地支六冲

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

```liuchong
```

**冲不等于凶**。冲的本质是两字对位、五行相克且方向相反：

- **主冲与被冲**：双方强弱决定谁主动谁被动。
- **冲的表现**：移动、变化、分离、激活、拆开。
- **应期**：原局有冲，遇大运流年再冲，可能应事；原局无冲，遇冲要看承载。

举例：示例盘地支 **丑　寅　子　寅**。四支之间无一对相冲。但日支子遇流年午（如2026丙午年），即**子午冲**，引动日支（配偶宫）——传统多读为家庭或感情主题被引动。但午的本气丁火对甲日主是**食神**（甲生丁、阴阳异），所以这个冲同时是"食神引动配偶宫"，要结合食神象义（表达、产出、子女）与现实处境，不能直断吉凶。

**逢冲不破合的常见误判**：原局子丑合，遇流年午——子午冲看似破子丑合，但若流年一过，合仍存在。流年冲只能"暂时引动"，不能"永久破合"。

## 七 · 地支三刑

寅巳申无恩之刑、丑戌未恃势之刑、子卯无礼之刑、辰午酉亥自刑。

```sanxing
```

刑的本质是**结构内部不顺**——不像冲那样正面对撞，而是在配合中反复牵制、内耗。三刑成立需要相关字都在场：

- **寅巳申无恩之刑**：三字齐全。传统读为"恩将仇报"或"知恩不报"，但实战多指"付出与回报不成比例"的人际模式。
- **丑戌未恃势之刑**：三字齐全。多读为"恃势相刑"——凭借资源或位置互相牵制。
- **子卯无礼之刑**：子卯两字。多读为"无礼"或"桃花"——长辈关系、礼节、情感主题。
- **自刑**：辰见辰、午见午、酉见酉、亥见亥。同字再见，结构性内耗。

举例：示例盘地支 **丑　寅　子　寅**。无寅巳申三字（缺巳申），无丑戌未三字（缺戌未），子卯无礼需要卯在场（本盘无卯），自刑需要同字再见（本盘寅再见寅——**寅见寅不为自刑，自刑只在辰午酉亥四字**）。本盘无刑成立。但子单见，若大运或流年遇卯，构成子卯刑，传统读为长辈关系或桃花主题被引动，需要结合现实。

**刑的判断难点**：刑不直接对应事件，更多是"结构反复"——同一主题在不同时段反复出现。配合十神看：刑在哪一柱、对应哪一宫、引动哪一十神。

## 八 · 地支六害

子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害。

```liuhai
```

害又称**穿**。两字本非相冲位置，却因六合被冲位破，形成暗中损耗。其影响通常**小于冲与刑**。

**害的来历**（口诀记忆）：

- 子丑合，午冲子 → 子未害（未与午同位冲方）
- 丑午害（同上对位）
- 寅亥合，巳冲亥 → 寅巳害
- 卯戌合，酉冲卯 → 卯辰害（辰与酉同位）
- 辰酉合，卯冲酉 → 不直接成害，需看具体配置
- 巳申合，寅冲申 → 申亥害
- 午未合，子冲午 → 那一组是子未害的另一种来源

举例：示例盘地支 **丑　寅　子　寅**。日支子与时支寅非六害关系。日支子与年支丑——子丑本合，不在六害。本盘无六害成立。但日支子若遇大运未，子未相害——要观察未在原局有没有根，以及是否同时与其他字形成冲合。

**害的实战定位**：害不破合、不破冲、不破刑。它是"背景噪音"——只有当冲刑合都不在场时，害才浮出水面成为主要线索。

## 九 · 合冲刑害如何叠加判断

实际断盘时，同一组地支可能同时存在多种关系。判断次序建议：

1. **先看大势**：原局五行谁最旺、谁最弱？月令是不是这一方？
2. **再看合会**：有没有三合/三会大环境？它会把整盘气势拉向哪一方？
3. **看冲**：哪一对在正面对撞？是否破合？
4. **看刑害**：内部损耗如何影响配合？
5. **看引动**：当前大运流年把哪一对关系激活？

**力量层级（通行参考，非绝对）**：

```
三会 ＞ 三合 ＞ 六冲（可破合） ＞ 六合 ＞ 三刑 ＞ 六害
```

**关键原则**：

- **冲能破合**：子午冲破子丑合（但流年冲只能暂时引动）。
- **刑不破合**：刑只减弱合的力量，不破合的关系。
- **多种关系同时存在时，以"动"为主**：岁运引动哪个就看哪个。
- **原局关系 vs 岁运关系**：原局有的关系是常态，岁运带来的是临时引动，前者定性格底色，后者定应期。

举例：示例盘地支 **丑　寅　子　寅**。

- 大势：寅木两见、月令寅木当令，木气偏旺。
- 合会：无三合三会成立。
- 冲：原局无冲。
- 刑害：无刑害成立。
- 引动窗口：日支子——遇午冲、遇辰半合水、遇卯刑、遇未害。**不同流年引动不同关系，应事主题不同**。这是断流年的关键逻辑：不是"子一定对应某事"，而是"子遇到什么字，对应什么主题"。

## 十 · 在你盘上怎么看

当前项目"盘面总览"的强弱粗评**尚未把合冲刑害与会局纳入记分**——这是已知的简化边界，页面会明确标注"简化粗评"。

理解到这一层后，你可以在自己盘上手动练习：

1. 列出地支四字（年支、月支、日支、时支）。
2. 圈出每对可能的**合 / 冲 / 刑 / 害 / 会**关系。
3. 标出哪一对最可能被当前大运或流年引动。
4. 写一句不带吉凶的描述："今年 X 字加入，与原局 Y 字形成 Z 关系，引动 [宫位] 与 [十神] 主题。"
5. 再问现实里有没有对应的人事主题。

第 4 步是关键：把抽象的"子午冲"翻译成"今年可能引动配偶宫、对应食神主题"——再回到现实处境核对，而不是直接断吉凶。

## 自测

任选自己盘的地支四字，回答：

1. 哪几对构成**六合**？哪几对构成**六冲**？
2. 有没有**三合**或**三会**的可能（含半合）？
3. 有没有**三刑**或**自刑**的字？
4. 哪一对最可能被今年流年引动？为什么？
5. 写一句"今年 X 关系被引动，对应 Y 宫位 Z 十神"的描述，再问现实里有没有对应主题。

答不出时，回到本页点击对应图表，再用[命理交叉速查](/learn#mingli-dizhi)核对单字五行藏干。

> 边界：字间关系是结构性影响，不是事件判决。所有关系成立后，仍要回到现实处境与十神喜忌来判断。"原局有冲就凶"或"有合就吉"都是简化误读，本项目禁止用单一关系下恐吓式断语。
