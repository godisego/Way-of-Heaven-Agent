# 天干五合与地支合冲刑害会：从单字到字间关系

排盘只数八个字的天干地支，远远不够。两个字相邻或对位时，会发生**合、冲、刑、害、会**等关系——传统命理用这些关系讨论联结、对撞、牵制与岁运引动。可以把单字看成独立的服务器节点，字间关系看成节点之间的网络拓扑：同一组节点，连法不同，系统行为完全不同。

速查入口：[天干](/learn#mingli-tiangan) · [地支](/learn#mingli-dizhi) · [藏干](/learn#mingli-canggan) · [十神](/learn#mingli-shishen) · [月令](/learn#mingli-yueling)。

## 一 · 为什么要看字间关系

| 关系 | 作用方向 | 一句话记忆 | 软件比喻 |
| --- | --- | --- | --- |
| 合 | 联结 / 转化 | 两字或多字结成一股合力，可能改五行 | 服务间建立连接，可能改变数据流向 |
| 冲 | 对撞 / 拆开 | 十二支圆周位置正对，不一定五行相克 | 节点对位冲突，原有结构被冲散或激活 |
| 刑 | 牵制 / 反复 | 结构内部不顺，内耗与反复 | 模块循环依赖，配合中反复牵制 |
| 害（穿） | 隐损 / 不和 | 表面无冲突，配合时却互相损耗 | 接口签名兼容，运行时却暗耗资源 |
| 会（三会） | 同方聚集 | 同一季节的三支构成一组 | 同机房服务器组成集群 |
| 三合 | 远联结成局 | 三字定方向、中字为局神 | 跨节点形成协同管道，方向一致 |

关键认知：**“出厂参数、运行时拓扑”只是帮助记忆的类比**，不是传统术语或已验证的现实规律。先确认配对，再讨论成立条件与解释；识别出关系，不等于已经证明合化、强弱或现实事件。

## 二 · 天干五合

甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火。

```tianganhe
```

**合化不是看到一对就化**。下面是本课采用的简化检查项；各流派对成立与合化条件有分歧，不能当作统一充分条件：

1. **位置**：先记两干是否相邻（年月、月日或日时）；隔柱能否论合、合力如何，要注明采用的读法。
2. **化神有根**：化神五行在月令或周边地支有根气支持。
3. **不被克破**：没有其他天干地支明显克制化神或合干之一。

举例：符号教学盘 **乙丑　戊寅　甲子　丙寅**，明干之间没有五合配对。若另造一组包含戊、癸的符号排列，可以讨论戊癸配对，但月干与时干之间隔着日柱，不能称相邻。寅中本就藏丙，不能说只有巳午未月才有火根；有根与具备合化条件也不是同一件事。修改单个柱的符号练习不保证仍符合实际出生历法，应与完整排盘区分。

**合而不化的意义**：一些读法称为“合绊”，用来讨论两干的牵制。它不是可统一量化的力量折扣，不能据此给两干自动减分。

## 三 · 地支六合

子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合（午未合流派不一，有合化火、合化土、合而不化三说）。

```liuhe
```

六合首先是一张配对表，**相邻不是识别六合配对的必要条件**。论作用和合化时，再检查：

1. **位置与时间层次**：两支在哪两柱，是原局已有，还是岁运加入；是否相邻分别记录。
2. **化神条件**：所采用流派要求的月令、根气与透干条件是否具备。
3. **生克与冲刑**：同柱干支及其他字是否参与牵制，不能见到配对就把原五行改掉。
4. **关系重叠**：同一个字是否兼属三合、三会或冲刑；逐条列出，不预设三合永远覆盖六合。

举例：示例盘地支 **丑　寅　子　寅**。年支丑与日支子已经构成六合配对，但并非相邻柱。只做地支练习时，可把时支暂换成丑，比较相邻与隔柱的区别；若连同甲日的时柱一起改写，应按五鼠遁写作**乙丑时**，不能写“丙丑时”。这里是符号练习，不将改柱后的组合冒充真实出生排盘。子丑虽属合土一组，是否合化仍须另行检查。

**六合不化的常见误用**：看到子丑就宣布“水变土”。配对只回答“是哪种关系”，合化条件要另行判断；条件不足时保留原五行，是否解释为合绊也应注明口径。

## 四 · 地支三合局

申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。

```sanhe
```

三合的特点：

- 三字齐全才具备完整三合组合；能否按合化局论，还要看采用流派的条件。
- **半合**通常指包含旺支的两字，如申子、子辰；缺旺支的申辰常称**拱合**，不能把任意缺一字都叫半合。
- **中字为局神**，力量集中：申子辰中的子、亥卯未中的卯、寅午戌中的午、巳酉丑中的酉。
- 三合常用于讨论某一五行的集中趋势，但不能仅凭“三合”二字就宣布压过所有其他关系。

举例：示例盘地支 **丑　寅　子　寅**。无申、无辰，子水单见，三合水局不成立。但子是水局的中字——若大运或流年遇申或辰，可识别申子或子辰半合组合，但不能直接宣布完整水局成立。水对甲木属印星，这是讨论印星主题的一条传统解释线索。

**半合的判断**：申子、子辰含旺支子，申辰则缺子，应分别标注；“半合”也不表示强度恰好是完整三合的一半。见辰不能自动宣称“水库大开”，还需交代月令与其他字的条件。

## 五 · 地支三会局

寅卯辰会木方、巳午未会火方、申酉戌会金方、亥子丑会水方。

```sanhui
```

三会由同一季节、同一方位的三支组成。这里“相邻”指十二支序列中的季节连续性，**不等于要求三支必须落在相邻三柱**。先识别三字是否齐全，再注明月令、位置与冲克等条件；不同流派对是否按会局论及其强度有不同要求。

举例：示例盘地支 **丑　寅　子　寅**。寅出现两次，但缺卯、辰，寅卯辰三字不齐，三会木方不成立。若大运逢卯、流年逢辰，原局与岁运合看可补齐三会木方组合；应标明两个字来自岁运，再按选定读法讨论比劫主题，不能把它当作原局本来就有的会局。

**三会与三合的取舍**：二者都是检查全局结构的线索。不能统一规定“三会必强、三合必温和”，更不能跳过月令、透干与冲克，直接决定喜忌。

## 六 · 地支六冲

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

```liuchong
```

**冲不等于凶**。六冲是十二支圆周上相隔六位的对位配对。**并非每组五行相克：辰戌、丑未双方都属土**。配对之后，传统读法还会讨论：

- **主冲与被冲**：双方强弱决定谁主动谁被动。
- **冲的表现**：移动、变化、分离、激活、拆开。
- **应期**：原局有冲，遇大运流年再冲，可能应事；原局无冲，遇冲要看承载。

举例：示例盘地支 **丑　寅　子　寅**。四支之间无一对相冲。但日支子遇流年午（如2026丙午年），即**子午冲**，引动日支（配偶宫）——传统多读为家庭或感情主题被引动。午的本气丁火对甲日主是**伤官**（甲生丁、阴阳异；同阴阳的丙才是食神）。若按本气讨论，可记为“日支子遇午冲，并涉及伤官主题”；午还藏己土，流年天干丙又属食神，不能把整个流年缩成单一十神。以上只是传统解释线索，不是对感情事件的判定。

**冲合并见的处理**：原局子丑配对，流年午加入时，子午冲与丑午害也同时存在。先保留全部关系，再按选定读法判断作用；岁运加入的字不会改写出生四柱，不能把“破合”的解释误当作删除原局数据。

## 七 · 地支三刑

寅巳申无恩之刑、丑戌未恃势之刑、子卯无礼之刑、辰午酉亥自刑。

```sanxing
```

刑常被传统读法解释为牵制与反复。先识别下列组合，再区分完整三刑与两字相刑的口径：

- **寅巳申无恩之刑**：三字齐全是完整组合；有些读法也分别论寅巳、巳申、申寅两字相刑，须注明口径。“无恩”是传统名称，不能据此给人贴道德标签。
- **丑戌未恃势之刑**：三字齐全是完整组合；两字是否论刑同样存在读法差别。它与丑未冲等配对可以重叠。
- **子卯无礼之刑**：子卯两字配对；“无礼”不等于当事人失礼，也不能据此判断人品。
- **自刑**：辰见辰、午见午、酉见酉、亥见亥。是四类同字重复，不是辰、午、酉、亥彼此互刑。是否论作用仍应注明采用口径。

举例：示例盘地支 **丑　寅　子　寅**。无寅巳申三字（缺巳申），无丑戌未三字（缺戌未），子卯无礼需要卯在场（本盘无卯），自刑需要同字再见（本盘寅再见寅——**寅见寅不为自刑，自刑只在辰午酉亥四字**）。本盘无刑成立。但子单见，若大运或流年遇卯，构成子卯刑，传统读为长辈关系或桃花主题被引动，需要结合现实。

**刑的判断难点**：刑不直接对应事件，更多是"结构反复"——同一主题在不同时段反复出现。配合十神看：刑在哪一柱、对应哪一宫、引动哪一十神。

## 八 · 地支六害

子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害。

```liuhai
```

害又称**穿**。配对可借助六合与六冲来记忆，传统常以不和或牵制解释；这种解释不代表已经测量出“损耗”，也没有跨流派统一的强度分值。

**六害的配对推导**（记忆方法）：若 A 与 B 六合，C 冲 B，则检查 A 与 C 相害。按“谁合谁 → 谁冲谁 → 谁与谁害”逐步核对：

- 子丑合：未冲丑 → **子未害**。
- 子丑合：午冲子 → **丑午害**。
- 寅亥合：巳冲亥 → **寅巳害**。
- 寅亥合：申冲寅 → **申亥害**。
- 卯戌合：辰冲戌 → **卯辰害**。
- 卯戌合：酉冲卯 → **酉戌害**。

以上三组六合的两个方向恰好得到六对害；其余三组六合也可反向复核同样的六对。这里的推导用于记表，识别六害配对时不要求作为中间步骤的那个六合伙伴也出现在盘中。

举例：示例盘地支 **丑　寅　子　寅**。日支子与时支寅非六害关系。日支子与年支丑——子丑本合，不在六害。本盘无六害成立。但日支子若遇大运未，子未相害——要观察未在原局有没有根，以及是否同时与其他字形成冲合。

**害与其他关系可以并存**：例如寅巳在部分读法中既论刑又论害。不要把六害规定为“只有冲刑合不在场才有效”；应记录叠加关系和所用流派，再讨论解释边界。

## 九 · 合冲刑害如何叠加判断

实际断盘时，同一组地支可能同时存在多种关系。判断次序建议：

1. **先看大势**：原局五行谁最旺、谁最弱？月令是不是这一方？
2. **再看合会**：有没有三合/三会大环境？它会把整盘气势拉向哪一方？
3. **看冲**：哪一对在正面对撞？是否破合？
4. **看刑害**：内部损耗如何影响配合？
5. **看引动**：当前大运流年把哪一对关系激活？

**阅读顺序不等于力量排名**。没有适用于所有流派和所有盘的“三会 ＞ 三合 ＞ 冲 ＞ 合 ＞ 刑 ＞ 害”固定公式。本课用上面的顺序帮助查漏，不据此自动删掉其他关系或给强弱打分。

**记录时保留三件事**：

- **关系可以重叠**：冲合、刑合、刑害并见时，先列全，再解释；“冲一定破合”“刑永不破合”都不宜写成无条件规则。
- **条件需要说明**：月令、透干、位置与其他字的参与，是讨论成局、合化和强弱时的上下文。
- **原局与岁运分开**：出生四柱不随岁运改写；岁运补入的关系要标明时间层次，不能直接推出性格或事件。

举例：示例盘地支 **丑　寅　子　寅**。

- 大势：寅木两见、月令寅木当令，木气偏旺。
- 合会：年支丑与日支子是六合配对；无完整三合、三会组合。
- 冲：原局无冲。
- 刑害：无刑害成立。
- 引动窗口：日支子——遇午冲、遇辰半合水、遇卯刑、遇未害。不同岁运字会补入不同关系；结构变化可以复算，是否与现实事件有关则是另一个需要证据的问题。

## 十 · 在你盘上怎么看

当前项目"盘面总览"的强弱粗评**尚未把合冲刑害与会局纳入记分**——这是已知的简化边界，页面会明确标注"简化粗评"。

理解到这一层后，你可以在自己盘上手动练习：

1. 列出地支四字（年支、月支、日支、时支）。
2. 圈出每对可能的**合 / 冲 / 刑 / 害 / 会**关系。
3. 标出哪一对最可能被当前大运或流年引动。
4. 写一句不带吉凶的描述："今年 X 字加入，与原局 Y 字形成 Z 关系，引动 [宫位] 与 [十神] 主题。"
5. 再问现实里有没有对应的人事主题。

第 4 步是关键：把抽象的“子午冲”写成可核对的关系说明。例如甲日主、日支子遇午，可写“子午相冲，午中丁对甲为伤官”；若再采用宫位象义，应明确那是传统解释。不要用现实经历反推所有配对都有效。

## 自测

任选自己盘的地支四字，回答：

1. 哪几对构成**六合**？哪几对构成**六冲**？
2. 有没有**三合**或**三会**的可能（含半合）？
3. 有没有**三刑**或**自刑**的字？
4. 哪一对最可能被今年流年引动？为什么？
5. 写一句"今年 X 关系被引动，对应 Y 宫位 Z 十神"的描述，再问现实里有没有对应主题。

答不出时，回到本页点击对应图表，再用[命理交叉速查](/learn#mingli-dizhi)核对单字五行藏干。

> 边界：字间关系是结构性影响，不是事件判决。所有关系成立后，仍要回到现实处境与十神喜忌来判断。"原局有冲就凶"或"有合就吉"都是简化误读，本项目禁止用单一关系下恐吓式断语。

## 核对依据

六害配对、六合、三合及三刑名称可对照[《三命通会》卷二](https://zh.wikisource.org/wiki/三命通會/卷二)的对应章节。本课的六害六步链是根据配对表整理的记忆法，不冒充古籍逐字引文；网页转录仍应注意异体字与校勘。关系表可以核对，合化条件与象义则应区分流派，传统出处也不构成现实预测有效性的证据。
