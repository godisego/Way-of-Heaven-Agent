# 调候：按日干与月令查条件

先修：[格局与用神](/learn/bazi-gege-yongshen)。本课目标是学会查明调候说法的适用条件，而不是背一张“冬天补火、夏天补水”的处方表。

调候以寒暖燥湿解释命局，是传统象征语言。它既不测量人体温度，也不是当地气象模型；没有据此证明出生季节能够决定人格或人生结果。

## 一 · 为什么不能把十二个月压成冬夏两栏

寅、卯、辰同属春季，月令和藏干却不同。初春可能仍讨论余寒，辰月又有湿土语境。同一月份，对甲木与丙火的读法也不同。把十个日干各配一个“冬月首选、夏月首选”，会抹掉原书条件甚至把生扶与制约混为一谈。

| 查阅步骤 | 需要记录 |
| --- | --- |
| 定日干 | 甲、乙等具体天干，不能只写“木” |
| 定节气月 | 寅月、卯月等，不用公历月份替代 |
| 找章节 | 如《穷通宝鉴》的“甲木寅月”条目，标明版本与页码 |
| 提取条件 | 原文讨论哪些干支、有无根气、透藏或组合限制 |
| 对回全盘 | 条件哪些满足、哪些不满足、哪些未判断 |
| 比较其他读法 | 扶抑与格局是否给出不同方向；保留分歧及依据 |

本课移除了按冬夏概括十干的速成口诀表。没有核对到具体版本的条目，写“待查”，不要补出一个貌似完整的答案。

## 二 · 调候与扶抑要分开陈述

调候侧重寒暖燥湿的象义，扶抑侧重生扶与克泄耗。两者可能一致，也可能不同；不同作者对其重要程度的处理不一，没有全体系统一优先级。

判断丙火对某日主的关系时，必须先换算十神。例如甲日主见丙为食神，戊日主见丙为偏印。不能笼统写“冬月需要火，所以需要印”。

## 三 · 教学案例

同一案例 **乙丑　戊寅　甲子　丙寅**：

1. 日主甲，节气月为寅；要查的是“甲木寅月”，不是所有春季日主通用规则。
2. 先记录丙在时干透出，寅中亦藏丙，这是可以核验的符号事实。
3. 是否符合某书的调候取用，需要引用该条条件，并检查水、土等其他配置。
4. “有丙”并不自动意味着“调候成立、人生必顺”；未查原文时，结论止于第 2 步。

不要任意替换一柱就宣称获得了另一个真实出生盘。改月柱用于抽象关系练习时，应明确“符号假设，尚未经历法复算”。

## 四 · 练习与参考要点

- 问：寅月是否一律不需要讨论调候？答：不是。应查具体日干、月令及全盘条件。
- 问：甲见丙与戊见丙，为什么不能都叫印生身？答：前者木生火为食神，后者火生土且同阴阳为偏印。
- 作业：选一个日干月令，提交原文位置、条件清单与未满足条件。评分看引用和推导是否一致，不按事后“算中了”评分。

## 来源与口径

《穷通宝鉴》按日干、月令分条的组织方式是本课查阅对象；不同重排与评注版的章名、页码会变化，提交作业时必须注明版本。本课没有提供未核对的逐月取用定论。十神定义可对照[《三命通会》卷六](https://zh.wikisource.org/wiki/三命通會/卷六)“论食神”“论印绶”。复核日期：2026-09-27。
