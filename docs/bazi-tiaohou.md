# 调候用神：寒暖燥湿的气候调衡

用神取法有五种——扶抑、调候、通关、病药、从格。前面[格局取用与用神详法](/learn/bazi-gege-yongshen)讲了扶抑优先级最低，调候排在从格之后、扶抑之前。这一课专讲调候——**看月令气候是否过寒或过燥，先于扶抑制衡气温**。

> **本课属于命理系统七层结构的第 5 层（算法层）**——是格局用神课的姊妹篇，补全用神体系最后一块。

速查：[月令](/learn#mingli-yueling) · [五行](/learn#mingli-wuxing-gk) · [用神扶抑](/learn#mingli-yongshen-fuyi) · [身强身弱](/learn#mingli-qiangruo)。

## 一 · 为什么要调候

古人观察：冬月万物闭藏，气过寒；夏月万物发散，气过燥。命局生于冬月，纵使日主身强，若无火暖，则"寒木不向阳"——再多的木气也难以萌发。生于夏月，纵使日主身弱，若无水润，则"燥土不生金"——再需要金气也难以成形。

**调候的本质：先于扶抑看气候——过寒需暖、过燥需润，让五行能在合适的"温度"下流动。**

| 月令 | 气候 | 调候方向 | 理由 |
| --- | --- | --- | --- |
| 亥子丑（冬三月） | 寒 | 取丙丁火暖 | 寒木不向阳，无火则水旺木漂、金寒不化 |
| 巳午未（夏三月） | 燥 | 取壬癸水润 | 燥土不生金、火炎土燥无生机 |
| 寅卯辰（春三月） | 温和 | 一般不论调候 | 木气旺而温和，看具体盘是否过燥 |
| 申酉戌（秋三月） | 凉 | 看具体盘 | 金气旺而凉，需火炼金则取火，否则不论 |

## 二 · 调候口诀

调候用神传统上有口诀传世，最通行的是《穷通宝鉴》的"日干逐月调候表"。这里给一个简化版：

| 日主 | 生于冬月（亥子丑）调候 | 生于夏月（巳午未）调候 |
| --- | --- | --- |
| 甲木 | 丙火为首选（暖木向阳） | 癸水为首选（润木不枯） |
| 乙木 | 丙火为主、甲木为辅 | 癸水为主、丙火为辅 |
| 丙火 | 壬水为辅（火寒需助又需制） | 壬水为首选（制火过旺） |
| 丁火 | 甲木为首选（生丁火助光） | 壬水为首选（调候又合） |
| 戊土 | 丙火为首选（暖土生万物） | 癸水为首选（润土不燥） |
| 己土 | 丙火为主、丁火为辅 | 癸水为主、丙火为辅 |
| 庚金 | 丁火为首选（炼金成器） | 壬水为首选（润金不脆） |
| 辛金 | 壬水为首选（洗金见光） | 壬水为主、己土为辅 |
| 壬水 | 戊土为首选（止水不泛滥） | 辛金为辅（生水助源） |
| 癸水 | 丙火为首选（暖水化冰） | 辛金为首选（生水不竭） |

> **注意：这只是通行口径，具体盘要看调候用神是否在局中有根、是否被克破。** 口诀给方向，不替你判断。

## 三 · 调候与扶抑的关系

调候与扶抑可能一致，也可能矛盾：

| 情形 | 含义 | 处理 |
| --- | --- | --- |
| 调候与扶抑一致 | 如冬月身弱，需丙火暖又需印生身 | 一举两得，最顺 |
| 调候与扶抑矛盾 | 如冬月身强，调候需火但身强不宜印生 | **调候优先**——先解决气温，再论扶抑 |
| 无调候需求 | 春秋月生，温和 | 直接论扶抑 |

**关键认知：调候优先级高于扶抑。** 原因是气温不适则五行无法流动——纵使日主身强，无火暖的冬月木也难以泄秀生财。

## 四 · 举例

示例盘：**乙丑年　戊寅月　甲子日　丙寅时**。日主甲木。

- **月令**：寅月——春木，温和，**无调候需求**。
- 所以本盘不论调候，直接论扶抑（身强用克泄耗）。

若改为**乙丑年　己亥月　甲子日　丙寅时**（月令改亥）：
- **月令**：亥月——冬水寒。
- 调候：取丙火暖木向阳。本盘时干透丙火，**调候用神已透**。
- 但丙火坐寅，寅中藏丙——通根有力，调候成立。
- 扶抑：甲木亥月得令印生，身强；身强本不宜印比，但调候需火（食伤），恰好泄秀——调候与扶抑方向一致。

## 五 · 调候的边界

| 能做 | 不能做 |
| --- | --- |
| 标记原局是否过寒过燥 | 替代扶抑判断（调候只是优先项之一） |
| 提供气候维度的用神候选 | 直断"冬月必凶"或"夏月必吉" |
| 解释"为何身强却难发力" | 不结合格局与十神就单独取调候用神 |

调候是"看气温"——它告诉你这盘的"温度环境"是否合适五行流动，但不替你断吉凶。

## 六 · 自测

1. 你生于几月？是否属于需要调候的冬月或夏月？
2. 若需调候，你的日主对应何调候用神？局中有无此五行？
3. 你的调候用神与扶抑用神方向是否一致？

> 边界：调候是气候维度的用神取法，不是万能钥匙。古人讲"寒木向阳"是经验总结，不是物理定律——仍要结合格局、十神、岁运综合判断。
