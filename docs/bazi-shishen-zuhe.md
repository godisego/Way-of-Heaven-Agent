# 十神组合：先核对关系，再讨论解释

前置：[十神与强弱](/learn/bazi-ten-gods-strength)、[流派与证据边界](/learn/bazi-school-differences)。十神组合是传统解释语言；查到组合不证明对应职业、婚姻、健康或财富事件。以下是阅读传统文本时的观察框架，不是已经验证的预测规则。

## 一 · 十种常见讨论

| 组合 | 需核对的关系 | 传统讨论方向 |
| --- | --- | --- |
| 食神生财 | 日主所生且同阴阳为食神，其五行再生财星 | 输出与资源的关系 |
| 伤官见官 | 伤官与正官并见，检查其克制关系 | 输出与约束的关系 |
| 官印相生 | 官星生印星，印星生日主 | 约束、生扶的传递 |
| 杀印相生 | 七杀生印，印生日主 | 七杀与印的配合 |
| 财生官杀 | 财星五行生官杀五行 | 财与官杀的联系 |
| 枭神夺食 | 偏印克食神，还需核对食神是否为所用 | 偏印与食神的牵制 |
| 比劫夺财 | 比劫与财星的克制关系 | 同类与财星的联系 |
| 食神制杀 | 食神五行克七杀五行 | 食神与七杀的制约 |
| 伤官配印 | 印星克制伤官，判断配合条件 | 印与伤官的配合 |
| 财破印 | 财星五行克印星五行 | 财与印的牵制 |

“生”“克”先是五行表中的关系。传统作者还会考虑月令、位置、透藏、强弱和格局，不能用上表直接推出固定吉凶。所谓“身强一定好、身弱一定凶”也不是本课的验收答案。

## 二 · 怎样记录成立条件

先列出具体干支和十神，再写透干还是藏干、相隔位置、所采用的解释和来源。相邻、得令等是部分读法关注的条件，并非所有流派共同使用的一套程序。符号关系、解释条件与现实证据应分栏记录。

## 三 · 修正后的示例

符号教学盘：**乙丑　戊寅　甲子　丙寅**，日主甲木。

- 时干丙火对甲为**食神**，月干戊土为偏财；丙火生戊土，可讨论食神生财的关系链。
- 月干与时干之间隔着日柱，不应写成相邻。
- 子藏癸为正印；癸水与丙火有相克关系，但仅凭同盘出现不能直接认定组合已破或吉凶已定。
- 寅月对甲涉及建禄读法，不能因为戊透就自动指定偏财格。需要说明所用格局定义。

本例只示范术语和关系，不证明个人有创造力、会赚钱，或某年会发生事件。

## 四 · 柱位与时间层

年、月、日、时在传统文本中有不同象义，相关联想应明确标为传统解释，不能当作事件定位器。岁运增加参与比较的干支；不能把“遇印化吉”“见官应凶”作为无条件规则。先复算十神和组合，再记录来源、条件及尚不能判断的部分。

## 五 · 练习、参考与来源

1. 将示例盘丙对甲判作伤官，错在哪里？**参考**：甲丙同为阳，属于我生同阴阳，应为食神。
2. 丙、戊同时出现能否断定富裕？**参考**：只能先记录食神生财的符号链，解释条件与现实证据仍不足。
3. 为月干、时干各写一条可查事实和一条有条件的传统解释。**评分**：换算正确、位置正确、事实与解释分开，各一项；任一基础换算错误须订正。

术语参照[《三命通会》卷六](https://zh.wikisource.org/wiki/三命通會/卷六)的食神、伤官、财与印相关论述。不同章节的条件不能压缩为一张保证吉凶的表。综合作业见[统一案例与评分](/learn/bazi-capstone)。复核：2026-09-28。
