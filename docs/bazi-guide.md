# 八字排盘使用指南

本项目的排盘遵循「确定性优先」：四柱、藏干、十神、起运、大运、流年、神煞、宫位全部由代码（`lunar-javascript` + 自研规则层）算出，模型只解读、不推算。本文说明怎么用、算法采用了什么口径、每个口径为什么这么定。

### 理论框架与实战派：子平为体，盲派为用

本项目有意采用**双层命理设计**，两者不矛盾而是互补：

- **学习馆与排盘引擎 = 子平口径**（理论框架，"战略蓝图"）：四柱架构、十神关系、格局用神、起运大运——这些是子平传统派的标准体系，也是代码确定性推算的基础。学习馆的全部讲义、盘面释义的命理词条（约 100 条，覆盖概念/天干/地支/十神/五行/宫位/神煞/合冲刑害/十二长生/格局/用神/十神组合），都按子平理论解释，让你建立完整的理论框架。
- **老胡 = 盲派实战**（"具体对应战术"）：老胡的人设是盲派算师——盲派重象法、口诀、江湖经验，擅长直给"何时进、何时退"的判断。老胡基于同一张子平盘面，给出盲派视角的实战解读（批象论势、进退宜忌），把理论框架落地成你能用的行动建议。

简言之：**学习馆教你看懂盘的子平结构，老胡告诉你盲派实战里这盘怎么断**。

## 一 · 建立问者档

侧栏「卷一 · 问者档」→ 改档，填写：

- **出生日期与时间**（必填）：公历。时间影响时柱与真太阳时校正，尽量精确到分钟。
- **性别**（必填）：决定大运顺逆（阳年生男/阴年生女顺排，反之逆排）。
- **出生地经度**（建议填）：触发真太阳时校正；不填按北京时间直接排。
- **现居地、学历、工作、感情**（可选）：不参与排盘，仅作为三贤对谈的处境参考。

保存后卡片即显示完整盘面。档案只存在浏览器 `localStorage` 与本机 `data/`，不上传。

## 二 · 算法口径（每一条都可在代码中核验）

**真太阳时**（`src/core/user/solarTime.ts`）：校正 = 经度差（每偏离东经 120° 一度 ±4 分钟）+ **均时差 EOT**（地球轨道造成的 ±16 分钟内季节性偏差，按日期算）。校正若跨日（`dayShift`），日柱随之换日。卡片上会标注校正后时刻与偏移分钟数。

**晚子时**（23:00–24:00 出生）：两派可选（`lateZiRule`）——默认 `current-day`（晚子时日柱仍用当日，子平主流），可切 `next-day`（视作次日）。

**起运**（`qiYun`）：按出生到相邻节气的距离折算，输出**精确到「几年几个月几天」**（大师口径），并给虚岁上运年龄。两种折算（`qiYunConvention`）——默认 `traditional`（3 天 = 1 年，通行），可切 `exact`（按分钟精确折算）。大运每十年一换；上运前的年份以**小运**参看。

**流年**：以**立春**为界（不是正月初一），当年干支由公式推得；流年卡会标注它落在哪步大运内。

**藏干与十神**：地支藏干按主流序（本气在前）；十神以日干为轴查表。**神煞**取 `lunar-javascript` 输出并做安全降级（个别神煞历法源缺失时显示「暂缺」，不硬造）。**命宫、身宫、胎元**按传统公式另算。

## 三 · 界面怎么用

**五行着色**：盘面每个干支字按其五行取色——木绿、火朱、土赭、金褐、水黛（传统排盘着色法）。日柱天干即日主，以朱色底标注。

**点击释义**（命理规则引擎，约 100 词条交叉互链）：

| 点哪里 | 得到什么 |
| --- | --- |
| 整柱（如日柱丁卯） | 该柱宫位含义 + 干支关系（盖头/截脚/通根）+ 藏干十神 |
| 单个天干 / 地支 | 该字的五行阴阳本义 + 在你盘中的十神角色 |
| 起运行 | 你的上运时间、顺逆与「几岁几个月上运」的原理 |
| 某步大运 / 流年 | 干支对日主的十神、前五年后五年读法、所落大运 |
| 盘面总览 | **完整分析**（见下节） |

每张释义卡都可一键「**问三贤**」（把带盘面语境的问题递入茶案）或「**查典籍**」（在已入藏书籍中检索出处）。

## 四 · 盘面总览 = 完整分析

「盘面总览」不只教怎么看，而是对**你这张盘**做一遍完整的确定性走读，按读盘次序分八节：

1. **读盘四步**：方法论一句话版。
2. **日主与月令**：旺相休囚死判定（含依据）。
3. **强弱粗评**：月令 ±、地支通根（本气 +2 / 中余气 +1）、天干生扶 ±1 逐项记分，给出偏强/偏弱/中和与全部理由。
4. **五行分布**：本气计数、最盛之气与所缺之气（并说明「缺≠凶」）。
5. **喜忌方向（粗判）**：偏弱→宜印比，偏强→宜食伤财官；明示这只是方向、非定用神。
6. **十神偏重与性格线索**：天干透出计 2、支藏本气 2 中余气 1，排出偏重的十神类别（比劫/印/食伤/财/官杀）并给对应性格倾向提示。
7. **当前运程**：现在走哪步大运（对日主何十神）、今年流年（立春界）叠加提示。
8. **宫位一览**：命宫、身宫、胎元。

每节都标注局限（合冲刑害、调候、格局成败已有专课讲方法，但尚未纳入主算法自动记分——见 [干支合冲刑害会](/learn/bazi-branch-relations) 与 [格局取用与用神详法](/learn/bazi-gege-yongshen)）；结论定位是**自我观察材料**，不是判词。

## 五 · 三贤如何取用你的盘（分发三档）

排盘信息按人设分发（`src/core/mingli/chartBrief.ts`）：

- **老胡（全量档）**：拿到完整命理简报（四柱、十神、起运、大运、流年、神煞），并附使用规则——禁自算干支、禁恐吓式断语。
- **玄（气机档）**：只拿「气」的语言（强弱、五行盛衰、节奏），不批命。
- **李（隔离档）**：**完全不接触命理数据**，只拿现实处境；提示词层 + 程序校验双重禁止他使用干支话术。

## 六 · 边界

不做恐吓式预测；排盘是文化解释与自我观察的参考，不是医学/法律/投资依据；简化模型的每一处简化都在卡片里写明。相关设计详见 `docs/mentor-libraries-and-bazi-design.md` 与 `docs/design-language.md`。
