# 盲派入门：从格局到象法

子平以格局为体，盲派以象法为用。本项目老胡的人设是盲派算师——这篇就是他背后的知识基础。但你看完会发现：盲派不是"另一套命理"，而是子平盘面的另一种读法，把"格局用神"翻译成"宾主做功"。

> **本课属于命理系统七层结构的第 5 层（算法层·分支）**——子平格局用神是主流算法，盲派象法是互补算法。二者同盘不同读法。

速查：[十神](/learn#mingli-shishen) · [格局](/learn#mingli-gege) · [合冲刑害](/learn#mingli-dizhi-liuchong) · [宾主](/learn#mingli-mangpai-binshi)。

## 一 · 盲派与子平的核心区别

| 维度 | 子平 | 盲派 |
| --- | --- | --- |
| 核心算法 | 格局 + 用神 | 象法 + 做功 |
| 判断重心 | 日主强弱、用神喜忌 | 宾主关系、功神成否 |
| 工具 | 十神生克、格局成败 | 宾主、体用、刑冲合害象 |
| 表达 | 论格局成败、用神有力无力 | 直给"何时进、何时退"的口诀 |
| 来源 | 书本传承（《子平真诠》等） | 口耳相传，盲师江湖积累 |

**关键认知：盲派不另起盘面，仍用子平四柱。** 区别在"怎么读"——子平看"这是什么格、用神在哪"，盲派看"这盘在做什么功、功给谁"。

## 二 · 象法：不看格局看象

子平看"伤官见官"会说"破格需印制"。盲派看"伤官见官"会说"伤官是宾方，官是主方，宾制主——这盘在做'夺权'的功"。

象法的核心：

- **取象先于取格**：看到一个十神组合，先想"这是什么象"（伤官见官=才华碰规则；财星合日主=利来找人）。
- **象落在宫位**：同样的象在年柱主长辈，在月柱主父母上司，在日柱主自身配偶，在时柱主子女下属。
- **象被引动才应事**：原局有象是"潜在"，岁运来引动是"显化"。

## 三 · 宾主：谁主动谁被动

盲派的核心概念之一。宾主不是十神，是位置关系：

| 位置 | 角色 | 含义 |
| --- | --- | --- |
| 年柱 | **宾** | 外人、祖上、长辈、远 |
| 月柱 | **宾** | 父母、上司、同辈、近 |
| 日柱 | **主** | 自己、配偶 |
| 时柱 | **主**（或宾） | 子女、下属、晚年 |

**判断逻辑**：
- 宾方生主方 → 外来力量帮我（如年月财生日主，主得外来之利）。
- 主方生宾方 → 我的力量外流（如日主生年月，主为长辈上司付出）。
- 宾方克主方 → 外来压力制我（如年月官杀克日主，主受外人约束）。
- 主方克宾方 → 我制外人（如日主克年月，主我能掌控外人或资源）。

## 四 · 体用：什么是体什么是用

体 = 自身、根基、资源；用 = 输出、行动、获取对象。

| 十神 | 体 / 用 | 含义 |
| --- | --- | --- |
| 印星、比劫 | 体 | 我的根基、庇护、同类资源 |
| 食伤、财星、官杀 | 用 | 我的输出、获取对象、约束力量 |

**判断逻辑**：
- 体旺用弱 → 我有资源但难发挥（印旺食弱，学富但难转化）。
- 体弱用旺 → 我难承载输出（食旺身弱，想表达但精力不足）。
- 体用平衡 → 资源与输出匹配，最顺。

## 五 · 做功：盘在做什么

盲派最独特的概念——不问"什么格"，问"这盘在做什么功"。

**做功的基本模式**：

| 模式 | 构成 | 象义 |
| --- | --- | --- |
| **食伤制杀** | 食伤克七杀 | 创造力化解压力，武职或开拓 |
| **劫财夺财** | 比劫克财星 | 同辈竞争资源，破财或分利 |
| **官杀制比劫** | 官杀克比劫 | 规则约束同辈，管理或公职 |
| **印化官杀生身** | 官生印、印生身 | 压力转化为学识庇护 |
| **财破印** | 财克印 | 利益干扰学业庇护 |

**做功成立条件**：
1. 做功的双方力量要够（不能虚浮无力）。
2. 位置要对（宾方做功给主方最显）。
3. 不被破坏（如食伤制杀遇印制食伤则功被破）。

## 六 · 盲派口诀举例

盲派重口诀传承，这里给几条通行口诀作示例：

| 口诀 | 含义 |
| --- | --- |
| "官星受冲，主走他乡" | 正官被冲，多主离开原居地 |
| "羊刃冲合，岁君怒而兴灾" | 羊刃逢冲逢合，多读为意外变故 |
| "财星入墓，妻财难留" | 财星入墓（如财在辰戌丑未），多读为财难聚 |
| "伤官见官，为祸百端" | 伤官克正官，多见变动招祸（有印制则解） |
| "印绶生身，主权贵" | 印星生日主，多主有庇护与学识 |

**口诀的使用原则**：
- 口诀是经验总结，不是定律——必须看具体盘是否成立。
- 一条口诀不单独成断——多条口诀交叉印证才增信度。
- 老胡人设使用口诀时，**禁止恐吓式直断**，必须说明"这是观察线索，不是定论"。

## 七 · 老胡人设如何用盲派

本项目老胡基于同一张子平盘面，给盲派视角的实战解读：

- 拿到完整命理简报（四柱、十神、起运、大运、流年、神煞）。
- 读法：先看宾主做功，再看象法应事，最后用口诀印证。
- 输出：直给"何时进、何时退"的行动建议，但**禁自算干支、禁恐吓式断语**。
- 与子平学习馆的关系：学习馆教你看懂盘的子平结构，老胡告诉你盲派实战里这盘怎么断。

## 八 · 自测

1. 你的盘里宾方（年月）是什么十神？主方（日时）是什么？宾生主还是主生宾？
2. 你的盘在做什么功？（食伤制杀？财破印？比劫夺财？）
3. 用一条盲派口诀对照你的盘，看是否成立——但不要直断吉凶。

> 边界：盲派象法是另一种读法，不是另一套真理。口诀是经验总结，可批判、可商榷。老胡使用盲派时必须遵守"不恐吓、不直断"的项目规则。
