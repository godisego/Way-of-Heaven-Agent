# 七步读盘：从八个字走到可核对的判断

学完单个概念后，最容易卡在“都认识，但不知道先看谁”。这篇给出一条固定流程。它不是唯一流派，也不会把所有命理问题自动解完；价值在于让每一步都有输入、输出与边界。

示例仍使用：乙丑　戊寅　**甲**子　丙寅。

## 第一步 · 校验输入与历法边界

先确认出生日期、时间、地点和性别。检查是否靠近：

- 立春：可能影响年柱与生肖。
- 节气交接：可能影响月柱与月令。
- 23:00 与日界：涉及晚子时流派。
- 时辰边界：真太阳时校正可能改变时柱。

输出：一张口径明确、可以复算的四柱。输入不稳时，不进入后续细断。

## 第二步 · 找日主，建立坐标系

示例日干为甲，所以日主是阳木。此后每个天干和藏干都要相对甲计算十神。

输出：日主阴阳五行 + 十神换算坐标。此时只建立参照物，不凭“甲木”直接判性格。

## 第三步 · 看月令，确定季节基调

示例生于寅月，木气当令，甲木在寅得令。月令回答“整个环境当前最支持什么”，是强弱和取格的重要入口。

输出：旺、相、休、囚、死中的基调，以及月支藏干。此时仍不能只凭得令宣布身强，因为还要看根、透干与全局消耗。

## 第四步 · 查四支藏干与通根

示例四支为丑、寅、子、寅：

- 两个寅都藏甲，甲日主两见本气根。
- 子、丑中藏癸，能从印星角度生扶甲木。
- 藏干还带出伤官、财、官等关系。

输出：日主得地情况；每个外显天干有没有根；内部十神分布。这里把“页面层”与“服务器层”接起来。

## 第五步 · 看透干、十神与柱位

示例外显三干为乙、戊、丙，对甲分别是劫财、偏财、伤官。再看它们落在年、月、时哪一柱：

- 年干更接近早年和外圈环境。
- 月干贴近社会与青年环境。
- 时干偏向产出、子女与后段方向。

输出：哪些关系已经摆在台面上、落在哪个观察窗口。十神象义必须带位置，不做无位置贴标签。

## 第六步 · 评估流通、强弱与喜忌方向

按月令、通根、天干生扶做透明粗评，再观察五行生克是否形成流通：

```text
印星生身 → 日主生食伤 → 食伤生财 → 财生官 → 官生印
```

真实盘未必形成完整链条。强弱只告诉你承载能力的方向，喜忌粗判只告诉你更需要生扶还是克泄耗；真正用神还要考虑调候、格局与合冲。

输出：带理由的偏强 / 偏弱 / 大致中和 + 明确局限。

## 第七步 · 叠大运流年，并回到现实校准

先加当前大运，再加流年。不要从流年直接跳到事件，而要观察它引动原局哪组关系。

最后必须问现实：

- 这股“官杀”是在工作责任、考试规则，还是健康压力中出现？
- 这股“财”是收入、项目资源，还是持续消耗日主的经营任务？
- 盘面推测与真实经历不符时，是输入口径、简化算法、流派假设还是解释出了问题？

输出：一个可以被事实支持或推翻的假设，而不是无法证伪的判词。

## 一张检查表

| 步骤 | 必答问题 | 常见跳步 |
| --- | --- | --- |
| 1 校时 | 四柱边界可靠吗 | 不问出生地和边界时间 |
| 2 日主 | 坐标是谁 | 把生肖当成整张盘 |
| 3 月令 | 当令环境是什么 | 只数五行个数 |
| 4 根气 | 力量落地了吗 | 只看四个天干 |
| 5 十神位置 | 什么关系透在何宫 | 见一个十神就贴性格 |
| 6 强弱流通 | 承载和流向如何 | 把分数当精确科学 |
| 7 岁运现实 | 哪部分被引动、现实是否支持 | 从干支直跳具体事件 |

## 当前项目与完整传统判断的分界

项目当前已经确定性覆盖：四柱、真太阳时、藏干、十神、起运、大运、小运、流年、神煞、三宫，以及一套透明强弱粗评。

尚未完整纳入总览主算法：天干合化条件、地支合冲刑害优先级、调候、格局成败、从格与多流派校准。因此，系统的“盘面总览”对应这条七步流程的**入门骨架**，不是完整职业论命系统。

## 如何使用三贤而不把判断权交出去

1. 先在确定性盘面里指出事实：“甲日主、寅月、两个寅根、当前某大运。”
2. 再将现实问题说清：“我正在考虑换工作，主要约束是现金流和家庭责任。”
3. 请老胡谈时机与进退，请玄谈节奏；李只面对现实选择，不读取命理数据。
4. 要求建议落到可执行动作，不接受恐吓式必然结论。

这种顺序把命理当作提问框架，而不是替你决定人生的远程控制器。

## 毕业练习

不用术语堆砌，用 150 字写一段自己的盘面说明，必须包含：

- 日主与月令。
- 一处通根或无根证据。
- 两个透干十神及其柱位。
- 当前大运和流年只作为背景，不下具体事件断语。
- 一句算法局限。

然后打开“盘面总览”逐条核对。概念卡住时，从[命理交叉速查](/learn#mingli-riyuan)顺藤摸瓜。
