# 项目演进案例：从 RAG 蓝图到受控 Agent

> 案例选读，不是通用 Agent 必修定义。核对日期：2026-09-27。旧蓝图写于工具循环实现之前，本页按当前源码标明“原目标、已实现、仍未实现”，避免把历史计划当现状。先读 [当前架构](/learn/architecture) 和 [运行系统](/learn/agent-runtime-protocols)。

## 一 · 当时解决什么问题

早期版本固定执行检索与生成。升级目标是让模型在受限工具中决定下一步取证动作、观察结果并收尾，同时保存来源和执行记录。当前项目已经有受控工具循环，不能再说“尚无 Tool Use”或“每轮无状态”。

**学习目标**：识别设计意图与实现证据的区别；为新增能力说明需求、验收标准和取舍。Agent 没有统一的“六大件齐全才完整”门槛，多智能体、长期记忆、独立规划器按任务选择。

## 二 · 蓝图对照表

| 原计划 | 当前实现证据 | 仍未完成或不能据此证明 |
| --- | --- | --- |
| 模型动态取证 | `orchestrator.ts` 与三个工具 | 不是任意任务执行器；没有动态排盘或写业务系统工具 |
| 工具契约与边界 | `toolRegistry.ts` 参数、次数、等待超时 | 没有完整租户权限；超时不保证底层调用取消 |
| 证据独立管理 | `evidenceLedger.ts` 来源去重与编号 | 不自动证明每个结论被来源支持 |
| 计划与观察 | 调度提示词、一句话计划和观察摘要 | 没有独立任务分解器或计划持久化恢复 |
| 会话记忆 | `sessionStore.ts` 与 `contextBuilder.ts` | 跨会话偏好/经验记忆的确认、编辑、删除未实现 |
| 引用与角色校验 | 分库引用校验、声口规则、有限重试 | 不等于事实审查或完备安全过滤 |
| 可观测性 | 轨迹事件、前端面板、消息持久化 | 调用次数不是精确 Token 账单；还需业务级评测 |
| 多角色表达 | 一次生成中组织所选角色 | 不是多个独立 Agent 协作 |
| 质量门禁 | 单测、类型检查、构建与五场景脚本 | 一次历史验收不代表当前版本、所有模型持续通过 |

## 三 · 原设想里哪些还只是候选

`calculate_bazi`、`get_current_luck_cycle`、`recall_memory`、`save_memory`、`delete_memory` 是蓝图候选能力，**不在当前默认 Agent 工具清单内**。当前排盘由应用代码预先完成，问者档用于生成；模型没有获得任意修改用户资料的权限。

同样，独立风险入口、逐结论证据覆盖检测、Token/费用硬预算、可恢复持久任务和结构化多 Agent 交接，不应因为画在架构图上就视为已交付。是否实现，应以具体使用需求和对照评测为依据。

## 四 · 下一次演进如何做决策

以“跨会话记住用户偏好”为例：

1. **问题证据**：用户是否反复重述稳定偏好？会话历史是否已经足够？
2. **最小契约**：只存用户确认的偏好，带来源、更新时间和适用范围；不把模型猜测写成用户事实。
3. **生命周期**：查看、修改、删除、失效；敏感信息单独控制，检索时检查用户身份。
4. **比较**：无记忆、仅会话摘要、长期记忆三组，比较完成率、错用信息与维护成本。
5. **发布条件**：错误记忆纠正和删除传播通过后才开放；失败时能关闭记忆并回到原路径。

多 Agent 也应这样评估：先证明单个受控系统在某类任务上的不足，再比较分工收益与额外延迟、成本和协作错误。角色数量不是成熟度指标。

## 五 · 历史里程碑怎么读

M0–M5 是本项目从协议探测、工具与循环、界面到验收的实施切片；它们不是业界统一成熟度等级。旧设计曾考虑 JSON 行动协议兜底；当前实际实现是 Anthropic 与 OpenAI 兼容的原生工具协议，没有名为 `JsonProtocolTransport` 的实现。

[工具循环案例](/learn/agent-loop)说明当前机制；[验证计划](/learn/verification-plan)区分可执行门禁和未来需求；[M5 清单](/learn/m5-acceptance)保留历史验收方法，空白记录不能充当通过证据。

## 六 · 案例作业

任选“独立规划器、长期记忆、多 Agent”之一，交一页变更提案：具体失败案例、最小新增状态或工具、三项可判定验收、回退方式、与简单方案的比较。

**参考判断**：如果只是需要重复查询资料，改进检索与观察结构可能比增加规划器更直接；如果只是想让三个角色说话不同，先调角色契约与评价，不必拆三个 Agent。

**评分**：问题证据 2 分、边界与契约 3 分、可判定评测 3 分、成本与回退 2 分；至少 8/10，并且不得把计划写成已经运行。此分数仅用于本课练习。
