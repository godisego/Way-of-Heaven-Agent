# 命身宫与二德规则修正记录

复核：2026-09-28。此文为维护记录；学习入口见 [排盘指南](bazi-guide.md) 的算法口径。

## 命身宫推导

统一地支索引：子=0、丑=1、…、亥=11。输入月支来自节气月柱，年干来自排盘年柱，时支来自经过时间口径处理的时柱；不把农历月序直接代入地支索引。

令月支序为 m，时支序为 t，所有结果按正模归入 0–11。

- 命宫：正月寅对应子位，逆数到生月的锚点为 `2−m`；从生时顺数到卯需前进 `3−t`，故为 `5−m−t`。
- 身宫：子起正月顺数到生月的锚点为 `m−2`；时辰标签前进到酉需 `9−t` 步，而宫位每步逆行，故为 `(m−2)−(9−t)`，即 `m+t+1`。
- 五虎遁：甲己年丙寅、乙庚年戊寅、丙辛年庚寅、丁壬年壬寅、戊癸年甲寅，从寅顺排至宫支，包括子、丑。输出 `gan`、`zhi`、完整 `ganZhi`；`wuXing` 明确为支五行。

身宫的「逆推」指宫位移动方向，时辰标签仍顺序前进。把宫位和时辰标签同时反向，会得到另一个公式 `m+7−t`，不能拿它解释以下例题：

| 输入 | 命宫 | 身宫 |
| --- | --- | --- |
| 乙年申月寅时（1995-08-14 04:30，无经度校正） | 癸未 | 丁亥 |
| 戊年未月亥时 | 癸亥 | 己未 |

第二例见[《盲派命理钩玄》转载页](https://xm.yi958.com/gsqm/5390)的“定胎、命、身诀”。该页是转载，不作为三处独立来源或原书校勘证明。代码交叉核对使用本项目已安装的 [lunar-javascript](https://github.com/6tail/lunar-javascript/blob/master/lunar.js) 的 `getMingGong`、`getShenGong`；库的一致性不能单独证明传统权威性。

旧命宫表并非完全符合一个固定偏移公式：部分行还有重复地支。已删除手填表，以明确公式实现，并用十二月 × 十二时辰逐格推算及真实日期交叉校验。无效输入会报错，不再默认返回子宫。

## 天德与月德

十二月天德目标和月德分组见排盘指南。口诀核对[《御定星厯考原》卷三](https://zh.wikisource.org/zh/御定星厯考原_%28四庫全書本%29/卷3)，四维卦转支采用坤申、乾亥、艮寅、巽巳的项目口径。

查表只产生候选；候选干须见四柱明干，候选支须见四柱地支。返回结构为 `target: { kind, value }` 与全部实际命中 `positions`；未见返回 `null`。藏干不计作明干。月德同样补齐实见判断，变量改为按月支命名。其余按年支起的神煞范围保持明确。

## 回归与迁移

- 宫位：固定例题、144 月时组合的逐格推算、十年干五虎遁、子丑跨界、无效输入。
- 排盘集成：144 个真实日期时辰与历法库宫位比较；1995-08-14 和酉月寅时/卯时的天德有无对照。
- 二德：十二天德目标，明干及地支命中位置，全部未见、藏干不命中、十二月月德。
- 输出：真实出生输入经排盘后进入盘面解释与三贤简报。保留的展示夹具注明是合成数据，不用于证明算法。
