# 学习馆内容检查与本轮优化记录

检查日期：2026-09-21 至 2026-09-22。范围：AI / Agent 讲义、课程目录、术语、自测、学习馆页面、配套官网课程预览。

## 主要缺口与处理

| 原有问题 | 本轮处理 |
| --- | --- |
| 课程围绕项目实现分散，缺少统一概念坐标 | 用世界观、技术树、模型原理、工程、产品五层组织；开发语言留在附录 |
| 原理过于简略，混用架构、领域与学习范式 | 补感知到行动、多轴技术地图、Q/K/V 与完整 Transformer / 训练 / 推理链路 |
| 未覆盖 Jev 的设计思路 | 新增官方资料核对后的专题，区分类型约束、概率、confidence、校准和业务正确性 |
| Prompt 之后缺少上下文、记忆与运行系统知识 | 补会话状态、压缩、记忆治理、Harness、Workflow、checkpoint、幂等与恢复 |
| 协议与能力包容易混淆 | 对比 Tool Calling、MCP、A2A、Skills、多智能体与 Computer Use 的职责及边界 |
| 调试偏重源码，缺少产品评测闭环 | 补任务结果、轨迹、评分器、权限、成本、尾延迟、线上回流与回归 |
| 产品课存在未经验证的价格与替代人工收益断言 | 改用明确标注的教学假设，加入业务基线、错误代价与 Solution / FDE 交付物 |
| 部分旧课与题目说反循迹模式，误称 RAG 只能查一次 | 以源码修正；三贤多角色不等于三个独立 Agent |
| 温度、Token、引用校验和微调等有过度概括 | 修正固定 Token 比率、低温防幻觉、格式正确即事实正确等误导 |
| 文章链接表和课程白名单重复维护 | Markdown 链接由课程白名单生成；回归检查文章与题目指向 |
| 正文数字可能被行内代码占位符误删 | 修复 Markdown 渲染并加入回归测试 |
| 有本机错题记录时刷新出现 React 水合错误 | 初始渲染保持一致，挂载后加载本机错题 |

## 范围边界与后续维护

这轮补齐的是课程与学习体验。Jev、MCP、A2A、通用长期记忆、Agent checkpoint、Computer Use 等没有因此接入业务运行时；课程明确标注现有实现和扩展设计。

新技术条目应保留官方来源、核对日期、概念所属层、适用场景、项目实现状态与评测方法。供应商性能与价格不作为永久常量；新模型或协议出现时，先按五层归位，再按业务任务验证是否值得采用。
