# 天干、地支与藏干：从页面到服务器

这一课解决一个常见困惑：排盘上明明只有八个大字，为什么点击地支后又会冒出一到三个天干？答案是，盘面至少有**外显层、承载层、内部实现层**三层。

配套速查：[天干](/learn#mingli-tiangan) · [地支](/learn#mingli-dizhi) · [藏干](/learn#mingli-canggan) · [通根](/learn#mingli-tonggen)。

## 一 · 三层模型

| 层 | 命理术语 | 软件比喻 | 观察重点 |
| --- | --- | --- | --- |
| 外显层 | 天干 | 用户看到的前端页面、公开 API | 什么力量已经公开出现 |
| 承载层 | 地支 | 服务器、运行环境、季节性负载 | 什么力量在何种环境中落地 |
| 内部层 | 藏干 | 服务进程、数据库字段、依赖包 | 承载层里面实际包含什么 |

如果只看天干，就像只看产品截图判断整个系统；如果只数地支五行，又像只看服务器名称却不看里面跑了什么服务。藏干负责把两层接起来。

## 二 · 十天干速览

十干按木火土金水成对排列，每对前一个为阳、后一个为阴。

| 天干 | 阴阳五行 | 常用物象 | 学习抓手 |
| --- | --- | --- | --- |
| 甲 | 阳木 | 大树、栋梁 | 直上、结构、担当 |
| 乙 | 阴木 | 花草、藤蔓 | 柔韧、连接、适应 |
| 丙 | 阳火 | 太阳 | 外放、照见、传播 |
| 丁 | 阴火 | 灯烛 | 聚焦、文明、细致 |
| 戊 | 阳土 | 高山、城墙 | 承载、边界、稳定 |
| 己 | 阴土 | 田园、湿土 | 培育、吸收、调和 |
| 庚 | 阳金 | 刀斧、钢铁 | 决断、执行、变革 |
| 辛 | 阴金 | 珠玉、精工 | 精炼、标准、细节 |
| 壬 | 阳水 | 江海 | 流动、规模、远志 |
| 癸 | 阴水 | 雨露、泉水 | 渗透、感知、润泽 |

物象是记忆钩子，不是人格判决。不能因为日主是甲，就直接宣布某人一定像大树；还要看甲生在什么月、是否通根、周围有什么生克。

## 三 · 十二地支速览

地支同时关联节气月、时辰、生肖与藏干。月份按节气切换，不是农历初一。

| 地支 | 五行 | 节气月 / 时辰 | 藏干（本气在前） |
| --- | --- | --- | --- |
| 子 | 水 | 大雪后 / 23-01 | 癸 |
| 丑 | 土 | 小寒后 / 01-03 | 己、癸、辛 |
| 寅 | 木 | 立春后 / 03-05 | 甲、丙、戊 |
| 卯 | 木 | 惊蛰后 / 05-07 | 乙 |
| 辰 | 土 | 清明后 / 07-09 | 戊、乙、癸 |
| 巳 | 火 | 立夏后 / 09-11 | 丙、戊、庚 |
| 午 | 火 | 芒种后 / 11-13 | 丁、己 |
| 未 | 土 | 小暑后 / 13-15 | 己、丁、乙 |
| 申 | 金 | 立秋后 / 15-17 | 庚、壬、戊 |
| 酉 | 金 | 白露后 / 17-19 | 辛 |
| 戌 | 土 | 寒露后 / 19-21 | 戊、辛、丁 |
| 亥 | 水 | 立冬后 / 21-23 | 壬、甲 |

子、卯、酉只藏一个天干，气较纯；午藏丁己，虽以火为本气仍含土；辰戌丑未是四季土，内部成分更复杂。

## 四 · 藏干：服务器里到底跑着什么

以寅为例：寅的地支五行归木，但内部藏**甲、丙、戊**。

- 甲是本气：最能代表寅的主功能，像服务器的核心服务。
- 丙是中气：有稳定影响但不占主位，像常驻辅助服务。
- 戊是余气：力量更隐约，像特定条件下才会被调用的依赖。

示例盘为“乙丑 戊寅 甲子 丙寅”，日主甲。月支寅内部的甲、丙、戊相对甲日主分别是比肩、伤官、偏财。于是一个“寅”字里同时含有同类支持、表达产出与资源经营三种关系。

这就是为什么不能把地支只读成“一个木”。

## 五 · 通根：前端能力有没有后端支撑

某天干的五行在任一地支藏干中出现，就说它有根：

- 甲木见寅中甲，是通本气根，支撑最直接。
- 甲木见亥中甲，是在余气中有根，仍有支撑但层级不同。
- 甲木四支均不见木，则天干较虚浮，要看印星生扶和其他条件。

通根不是简单的“有根一定好、无根一定坏”，而是判断承载力。一个公开功能背后有真实服务，通常更经得起负载；但服务过多、资源堵塞，也可能形成另一种失衡。

## 六 · 月令：同一套代码运行在哪个季节

月支兼任月令，是四支中最重要的环境变量。甲木生在寅卯月，木气当令；生在申酉月，金气当令。日主相同，运行环境不同，起点就不同。

可以把月令理解为生产环境：

- 本地开发环境里跑得动，不等于生产高峰也跑得动。
- 某服务在流量旺季天然得到资源，另一服务则可能被挤压。
- 因此强弱判断先看月令，再看根和天干生扶。

项目使用旺相休囚死的简化关系给月令记分，详见[十神与强弱](/learn/bazi-ten-gods-strength)。

## 七 · 一柱内部的五种基本关系

同一柱的天干与地支可以出现：

1. **同气**：干支五行相同，上下一体。
2. **地支生天干**：坐下得生。
3. **天干生地支**：上气向下泄。
4. **天干克地支**：常称盖头。
5. **地支克天干**：常称截脚。

系统点击整柱时会确定性显示这一层，并补充是否通根。这里仍是单柱观察；完整判断还要看其他三柱是否接应。

## 八 · 地支之间还有哪些关系

支与支之间还会发生合、冲、刑、害、破、三合、三会等关系。可以先用“系统之间的连接方式”理解：

- **合**：建立连接，可能改变原有资源流向；不等于一律吉。
- **冲**：两个方向正面对撞，也可能表现为移动、变化、拆开；不等于一律凶。
- **刑**：结构内部不顺、反复牵制。
- **害**：关系不正面碰撞，却在配合中受损。
- **三合 / 三会**：多个节点形成更大的同类环境，成立要看条件。

当前“盘面总览”的强弱粗评**尚未把合冲刑害与调候纳入记分**，因此页面明确标注“简化粗评”。了解未计算什么，与了解计算了什么同样重要。

## 九 · 一个完整拆解例子

拆示例月柱“戊寅”：

1. 戊是阳土，摆在天干，表示土的力量已经外显。
2. 寅是阳木、立春后的月令，是全盘的生产环境。
3. 寅藏甲、丙、戊；本气为甲木。
4. 日主甲克戊，戊相对甲为偏财。
5. 寅中甲为比肩、丙为伤官、戊为偏财。
6. 戊土坐寅木，木克土，属于地支克天干的“截脚”关系。
7. 戊在寅中又藏有戊，仍有余气根；不能只见截脚就宣布戊完全无力。

一次拆解同时使用了阴阳五行、十神、月令、藏干、通根和单柱干支关系。命理学习真正的门槛不是背更多判词，而是**按层次组合信息**。

## 十 · 自测

任选自己盘中一个地支，回答：

1. 它的本五行、节气月和时辰是什么？
2. 它藏哪几个干，谁是本气？
3. 每个藏干相对你的日主是什么十神？
4. 盘上哪个外显天干在这里通根？
5. 它如果是月支，还比其他支多承担什么作用？

答不出时不要猜，直接使用[命理交叉速查](/learn#mingli-dizhi)，再回自己的盘点击该字核对。
