# 学习模式 v2 · 双学径学习中心

本项目为两件事而生，**重心是学 AI Agent**（把 RAG / Agent 机制亲手写一遍并做成可视教学），其次是学命理（把排盘变成可点击的教材）。学习模式是这个双重目的的总入口——本文档定义它的 v2 形态。

## 一 · 现状盘点（v1 已有）

| 部件 | 现状 | 问题 |
| --- | --- | --- |
| 学习开关（右下 dock） | 切 `body[data-learning]`，激活术语悬浮 | 只是开关，无内容入口 |
| 「循迹一观」导览 | driver.js 单条 8 步（上传→索引→问答→引用→反幻觉） | 只讲 RAG；无命理课、无 Agent 课；一次性、无进度 |
| 术语悬浮 | 7 个组件 13 处 `data-tip` 一句话解释 | 零散、无术语表、无「深入」出口 |
| 三份走读文档 | `docs/rag-*` `docs/agent-beginner-*` 内容扎实 | 界面上点不到，等于不存在 |
| 现有导览锚点 | `chat-panel / asker-profile / tavern-gallery / messages / chat-input / chat-submit / bazi-card / uploader-card / library-card` 九处 | 命理释义面板缺锚点（需补 `mingli-panel`） |

## 二 · 设计目标

1. 「学习」按钮点开的不再是开关，而是一个**学习中心**：两条学径、课程进度、术语表、文档直达。
2. 每课 = 一条**短 driver.js 导览（3~6 步）+ 一个实操任务 + 一篇对应文档节**——看完就动手，动手有反馈。
3. 教具优先用**真实系统本身**：你自己的盘、你上传的书、一次真实的检索与校验，而不是贴图。
4. 全部课程内容确定性生成或手写，遵循项目三原则；进度只存本机 `localStorage`。

## 三 · 课程表

本项目重心是 Agent 学习——**Agent 径排第一**，课程内容与实现严格同源（每课标注源码路径）。

### 学径一 · AI Agent：看懂机器怎么想（重心）

| 课 | 内容 | 教具（锚点） | 实操 |
| --- | --- | --- | --- |
| 1 RAG 之旅 | 摄取→切分取舍→embedding 与向量空间→余弦/topK→分库权限检索→cite_as 拼接→生成只是初稿 | `uploader-card / library-card / chat-input / chat-submit / messages` | mock embedding 上传样例并提问、核对出典 |
| 2 可信链 | 反幻觉三道关；越库作废与「三真夹一假」博弈；声口校验；定向重试仅一次的取舍 | `messages / chat-submit` | 问库外问题验证「暂未入藏」 |
| 3 工具循环 | ReAct；三工具说明书；受控执行（zod/限次/超时）；证据台账 ev_N；六个停止条件；侦探与作者双阶段提示词 | 讲义课（M4 后升级为轨迹面板实景） | `mode:"agent"` curl 一问，读 trace JSON |
| 4 人设工程 | 三件套（neverSay/styleSample/contrast）、铁律与自查、材料隔离（简报三档）、输出端声口兜底 | `tavern-gallery / messages` | 指认三人声口标记 |
| 5 Agent 全景图 | 六大件（Tool use/Planning/Memory/Reflection/Multi-agent/Evals）逐件对照本项目：已有的讲实现，没有的讲取舍 | 讲义课 | 对照 `docs/agent-blueprint.md` 写下一件要补的 |
| 6 轨迹调试 | 请求→调度→执行→观察→台账→校验六层定位；停止原因与失败回归 | `agent-toggle / trace-panel` | 固定一题，找到 trace 中第一处不合理动作 |

### 学径二 · 命理：学会看自己的盘

| 课 | 内容 | 教具（锚点） | 实操 |
| --- | --- | --- | --- |
| 1 认盘 | 四柱、日主为轴、五行着色、年月日时=时间轴 | `bazi-card` | 点自己的日柱看宫位卡 |
| 2 干支与十神 | 干支本义、藏干、十神生克口诀 | 单字点击 → `mingli-panel` | 点月支看藏干并跳交叉词条 |
| 3 时间轴 | 起运精确到年月日、大运、流年立春界、小运；原局→大运→流年三层叠读 | 起运/大运/流年行 | 写一句不带吉凶的岁运结构描述 |
| 4 完整分析 | 总览八节；强弱记分、喜忌粗判、十神偏重算法与局限 | `overview-btn → mingli-panel` | 读八节后把「问三贤」发出去 |
| 5 七步读盘 | 校时→日主→月令→根气→十神位置→强弱流通→岁运现实校准 | `bazi-card / overview-btn / mingli-panel` | 用 150 字说明自己的盘并写出算法局限 |

每条学径末尾有一行「毕业小考」：Agent 径=对照 `docs/agent-loop-design.md` 读懂一份真实 trace JSON；命理径=用自己的话给盘下一句判读并交给三贤验证。

## 四 · 机制设计

**学习中心面板**：dock 点开展开为纸质小面板（约 280px，沿用月白视觉语言）：学径一/二课程列表（完成态打勾，进度存 `localStorage` `learning.progress.v1`）、术语表入口、三份走读文档入口。原「循迹一观」并入学径二课 1。

**课程定义集中化**：`src/data/tours/` 每课一个文件导出 `DriveStep[]` + 前置条件（如未建档先引导去建档）；`tourController.startTour(lessonId)` 接受课程号并在完成回调里写进度。

**学习馆自身导览**：`/learn` 顶栏提供独立的 2 分钟导览，不计入 Agent / 命理课程数量。它先解释三模式入口和线性课程路线，再自动切到命理学径与命理速查，依次标出搜索分类、结果列表和当前词条详情。

**术语表**：现散落的 `data-tip` 文案迁移入 `src/data/concepts.ts` 统一维护，悬浮卡尾部加「深入 →」链接到对应文档小节；新增 `/learn` 页渲染术语表与三份文档（Markdown 直渲）。

**管线注解（轻量版轨迹，先于 M4 可用）**：学习模式开启时，`/api/chat` 返回附 `pipelineNotes`（检索命中数、各库分布、引用校验结果、是否重试），typing 区下方以小字实时显示——RAG 模式也能「看见机器在想什么」。

## 六 · 验收口径

- 关闭学习模式时零打扰：无面板、无下划线、无注解。
- 每课 ≤ 3 分钟走完；任何一步的宿主元素不存在时导览自动跳过并提示前置条件。
- 进度只写本机；清空档不清学习进度（两回事）。
- 课程文案与实现同源：改算法必须同步改课文（课文里凡引用口径处标注对应源码路径）。
