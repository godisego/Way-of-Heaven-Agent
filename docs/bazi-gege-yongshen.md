# 格局与用神：先声明读法，再推导

先修：[十神与强弱](/learn/bazi-ten-gods-strength)、[干支关系](/learn/bazi-branch-relations)。目标：区分月令格局、扶抑喜忌与调候，不把三种含义塞进同一个“用神”。这些是传统解释框架，不能从格局名称直接推定职业、性格或人生结果。

## 一 · “用神”在不同书中不是同一个意思

| 语境 | 本课如何使用 | 不应混淆 |
| --- | --- | --- |
| 月令格局读法 | 围绕月令所藏、透干与配合讨论取格及成败 | 用神不总是“最缺的五行” |
| 扶抑读法 | 根据日主生扶与克泄耗讨论平衡方向 | 粗评偏强不等于唯一用神已定 |
| 调候读法 | 根据日干、具体月令、寒暖燥湿讨论候选 | 不能只按冬夏查一张统一表 |

“管理型”“创造型”等现代比喻只是记忆标签，不是人格测量。

## 二 · 月令取格的入门检查

1. 确认日干和月支藏干，将藏干逐一换算为十神。
2. 查看月令藏干中哪些透出天干，记录本气、中余气及柱位。
3. 按所读书的规则讨论取格。杂气月、多干并透等情况需要单独说明。
4. 月令为禄、劫、刃等情况，先识别建禄、月劫或阳刃等专门讨论，不能一律跳过比劫、随便选一个透干当格名。
5. 取格之后仍要讨论相神、制化和破坏条件；有一个名称不等于“格局成立且结果已知”。

八类常见讨论包括官、杀、财、偏财、印、偏印、食神、伤官。例如甲日见辛为正官，见庚为七杀；见丙为食神，见丁为伤官。这张清单不穷尽所有传统格局。

## 三 · 五种分析视角

| 视角 | 先问什么 | 例子与限制 |
| --- | --- | --- |
| 扶抑 | 生扶、克泄耗的条件如何 | 偏弱常讨论印比；仍需说明月令、根气和位置 |
| 调候 | 具体日干与月令怎样讨论寒暖燥湿 | 寅月也不能一律宣布无调候需求 |
| 通关 | 是否存在需要中间环节的相克关系 | 木克土，可讨论木生火、火生土；火克金，可讨论火生土、土生金 |
| 病药 | 所采用读法认定的主要矛盾是什么 | “病药”是传统比喻，不是健康诊断 |
| 从格、化格 | 是否符合该书严格规定的特殊条件 | 从弱、从旺和化气的条件不同，不能用“毫无根气”统管所有特殊格 |

木与火、火与土本来相生，不能写成“木火相战用火通关”。五种视角也没有跨流派通用的固定优先级。若采用某位作者的先后规则，需写明出处及适用条件。

## 四 · 同一教学盘，哪些能确定，哪些仍需论证

统一符号案例：**乙丑　戊寅　甲子　丙寅**。它用于关系换算练习，不附带真实个人经历。

- 日主甲木，月支寅藏甲、丙、戊，对甲分别为比肩、食神、偏财。
- 甲在寅为临官；以建禄口径阅读，应先讨论建禄，不能仅因戊透就定为“偏财格”。
- 两个寅都藏甲，子藏癸可作为印星生扶的证据。这支持“生扶条件较多”的传统判断；不是精确量化的人格强度。
- 丙透时干，丙生戊，因此可以讨论食神生财的关系链。木、火、土相生的符号关系可核对，其现实效果仍未得到证明。
- 寅月可能仍有余寒。调候读法应按“甲木寅月”查具体章节，不能直接写春季无需调候。

合格结论示例：“按建禄口径先查月令；甲有两处本气根，丙食神与戊偏财透出，可进一步讨论食神生财。这里不自动指定唯一用神，也不推定现实职业或收入。”

## 五 · 项目边界与练习

盘面总览实现了月令、通根、天干生扶的简化记分及喜忌方向；尚未自动完成格局成败、合化、调候、从格成立的综合判定。人工补充阅读也不能保证预测更准确。

练习：解释为什么本例不能见戊就定偏财格，并分别写出扶抑、调候、通关要补查的一个条件。参考要点：寅为甲禄；扶抑需全局，调候需具体日干月令，通关需先证明确有相克矛盾及中间五行条件。综合练习见[统一毕业案例](/learn/bazi-capstone)。
