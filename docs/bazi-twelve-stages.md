# 十二长生：阶段名称与通根分开查

先修：[天干、地支与藏干](/learn/bazi-stems-branches)。目标：正确查出甲在丑、寅、未的阶段，并说明“长生阶段”为什么不等于藏干通根或现实命运。

十二长生是传统术语表：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。它借生命循环命名，不是生物学阶段，更不能用“死、墓、绝”预测死亡或灾难。

## 一 · 采用的查表口径

本课以常见的“阳干顺行、阴干逆行，戊随丙、己随丁”表作查表练习。另有按五行统一顺行等读法，比较时应标明口径，而不是把不同表混用。

| 日干 | 长生 | 帝旺 | 墓 |
| --- | --- | --- | --- |
| 甲 | 亥 | 卯 | 未 |
| 乙 | 午 | 寅 | 戌 |
| 丙、戊 | 寅 | 午 | 戌 |
| 丁、己 | 酉 | 巳 | 丑 |
| 庚 | 巳 | 酉 | 丑 |
| 辛 | 子 | 申 | 辰 |
| 壬 | 申 | 子 | 辰 |
| 癸 | 卯 | 亥 | 未 |

甲从亥顺行：亥长生 → 子沐浴 → **丑冠带** → 寅临官 → 卯帝旺 → 辰衰 → 巳病 → 午死 → **未墓** → 申绝 → 酉胎 → 戌养。

“庚长生于巳”是传统表的约定，不能用“火生金”解释；五行生克中仍是火克金、土生金。

## 二 · 阶段和通根是两张表

通根要检查地支实际藏干有没有同类根气。不能把长生、临官、帝旺统一换成“强根”，也不能把死、墓、绝统一换成“无根”。

以教学盘 **乙丑　戊寅　甲子　丙寅** 为例：

| 地支 | 甲的长生阶段 | 藏干 | 对甲的通根事实 |
| --- | --- | --- | --- |
| 丑 | 冠带 | 己、癸、辛 | 不藏木，没有木根；癸为生扶，不是木根 |
| 寅（月、时各一） | 临官 | 甲、丙、戊 | 各藏甲本气，可记录两处本气根 |
| 子 | 沐浴 | 癸 | 不藏木，没有木根；癸为正印生扶 |

反例：甲在未为“墓”，但未藏乙，不能因此说木气全无。阶段名与藏干证据不能互相替代。

## 三 · 当前项目实现到哪里

底层历法库提供十二长生查询，但本项目的排盘结果和盘面总览尚未完整接入这张表。当前强弱粗评检查的是月令、生扶和藏干通根，没有用长生阶段自动换算强弱分数。本页图示及速查词条属于课程参考，不代表盘面已经具有完整十二长生分析功能。

## 四 · 练习与参考答案

1. 甲见丑是什么阶段？**冠带**，不是墓；甲的墓为未。
2. 甲在子沐浴，是否说明子有甲的弱根？**不能**；子只藏癸，需区分印生和通根。
3. 乙的长生在午、帝旺在寅是否写反？在本课阴干逆行口径下没有写反；换表必须注明。
4. 大运遇“绝”可否写“将有灾难”？**不可**。合格描述是“按所用表查得绝位，阶段名不能推出现实事件”。
