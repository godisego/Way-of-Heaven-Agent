# 口径先行：规则、流派、算法与证据

这篇建议在入门时先读，进阶时再回看。目标不是替某一派站队，而是学会发现“同一词语，实际用了不同规则”。

## 一 · 先把四个层次分开

| 层次 | 可如何核对 | 例子 |
| --- | --- | --- |
| 传统符号规则 | 查明确的定义或表 | 本课程十神规则中，甲生丙、同阴阳为食神；甲生丁、异阴阳为伤官 |
| 解释与流派 | 查作者、版本、条件 | 月令用神、扶抑用神、调候用神不是相同定义 |
| 软件实现 | 查输入、设置、代码和测试 | 晚子时日柱归当天或次日；粗评权重是项目设定 |
| 现实证据 | 独立观察与事先规定的评价方法 | 能复算四柱不等于证明人格或事件预测有效 |

把食神和伤官写反属于本课定义内的错误，不能用“流派不同”开脱。不同术语表或解释发生分歧，也不能在没有检查的情况下直接断定其中一方有错。

## 二 · 流派名称不是互斥的三个标准学科

“子平”涵盖多种四柱文献与解释传统；“盲派”也不是统一教科书；“新派”是现代传播中的宽泛标签。格局、旺衰、调候、象法可以出现在不同作者的体系里，不能把每位作者硬塞进三种固定算法。

| 常见侧重点 | 读者要问 |
| --- | --- |
| 月令格局 | 如何定义用神？建禄、月劫如何处理？ |
| 旺衰扶抑 | 用什么判强弱？权重是否只是作者简化？ |
| 调候 | 对哪个日干、哪个月令、哪些附加条件？ |
| 象法、宾主、做功 | 宾主按位置还是按另一层关系划分？断语出处是什么？ |

不要从“主张宾主”推断某作者一定不论强弱，也不要把现代汇总表称为所有子平书共有的标准。

## 三 · 最容易混用的四处

- **晚子时**：项目默认日柱算当天，可选算次日。必须记录配置，边界盘可分别比较。
- **十二长生**：本课介绍阳顺阴逆表及另一类五行口径；主粗评暂未接入长生计分，不能说项目已统一按阴干随阳干计算。
- **用神**：月令格局、扶抑、调候先分别表述，再比较。没有“从 > 调 > 通 > 病 > 扶”的通用标准。
- **合化和关系强度**：查到合、冲组合，不等于已证实合化或事件。三合、三会、六合不能统一折成固定倍数。

## 四 · 本项目的明确口径

排盘使用 `lunar-javascript` 与自研规则层；年柱按立春、月柱按节气，晚子时及起运配置见[排盘指南](/learn/bazi-guide)。强弱粗评是课程辅助启发式，不是古籍原封不动的评分标准。

老胡、玄、李是应用的对话角色。人物提示词的“流派风格”不是算法准确率的证明；同一模型生成的多位角色观点，也不等于多个独立专家的证据。

## 五 · 练习与参考要点

甲日见丙，资料 A 写食神，资料 B 写伤官：先查两者是否都采用本课十神定义；若是，则 B 错。

甲见丑，资料 A 写冠带，资料 B 写墓：按本课甲从亥顺行表复算，A 正确；不能因“各有流派”而放弃校验。

甲木某盘，格局读法与扶抑读法给出不同“用神”：先把两个词的定义写开，再比较条件，不急于合并成一个答案。
