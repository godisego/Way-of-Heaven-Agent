# 流派差异：子平、盲派、新派

学完前面讲义，你可能会发现不同书或不同算师对同一张盘给出不同结论——这不是有人错了，而是命理有三大流派，各自口径不同。这一课不教新概念，只说清楚**分歧在哪、怎么取舍**。

> **本课属于命理学径的延伸阅读**——学完才能理解为什么不同书说法不同，避免混用口径。

速查：[格局](/learn#mingli-gege) · [用神](/learn#mingli-yongshen-fuyi) · [十二长生](/learn#mingli-twelve-stages) · [盲派](/learn#mingli-mangpai-xiangfa)。

## 一 · 三大流派速览

| 流派 | 来源 | 核心方法 | 代表经典 |
| --- | --- | --- | --- |
| **子平派** | 书本传承 | 格局取用、用神有力无力 | 子平真诠、滴天髓、穷通宝鉴 |
| **盲派** | 口耳相传 | 象法、宾主、做功、口诀 | 盲师口诀、师门传承 |
| **新派** | 近代发展 | 简化格局、强化十神组合 | 李涵辰《八字预测真踪》等 |

## 二 · 核心分歧

### 分歧 1：阴干长生位

| 子平派 | 盲派 |
| --- | --- |
| 阴干长生逆排（乙长生在午） | 阴干从同五行阳干取（乙也从亥取长生） |
| 理由：阴阳互根，阴干随阳干走 | 理由：盲派只认五行不认阴阳方向 |

**项目口径**：本项目采用阳干口径（即阴干从同五行阳干取长生），与盲派一致；阴干逆排口径在词条里注明，但不进入主算法。

### 分歧 2：格局取用

| 子平派 | 盲派 |
| --- | --- |
| 严格月令取格，看透干与成败 | 不重格局名，看宾主做功 |
| 八种普通格 + 五种特殊格 | 不分普通特殊，看实际做功模式 |
| 重视"格成则贵，格破则贱" | 重视"做功成立则有力，做功被破则无力" |

**项目口径**：学习馆按子平格局讲（[格局取用与用神详法](/learn/bazi-gege-yongshen)），老胡按盲派象法断（[盲派入门](/learn/bazi-mangpai-primer)）。两者同盘不同读法。

### 分歧 3：用神取法

| 子平派 | 盲派 | 新派 |
| --- | --- | --- |
| 扶抑 + 调候 + 通关 + 病药 + 从格，优先级从 > 调 > 通 > 病 > 扶 | 不重用神，重做功与功神 | 弱化调候与通关，强调"用神就是使日主中和的五行" |
| 重视"用神有力不被克破" | 重视"功神成立且不被破坏" | 重视"日主能否承载" |

**项目口径**：按子平五法取用，但在[调候用神详法](/learn/bazi-tiaohou)里调候优先于扶抑。

### 分歧 4：阴干合化

| 子平派 | 盲派 |
| --- | --- |
| 严格合化条件（化神得令有根、不被克破） | 重象法——合不论化与不化，合就是合 |
| 区分"合化"与"合而不化" | 不细分，看合住的是什么十神 |

**项目口径**：按子平严格条件讲（见[干支合冲刑害会](/learn/bazi-branch-relations)），但提示"合不论化与否，两干仍互相牵绊"。

### 分歧 5：大运流年

| 子平派 | 盲派 |
| --- | --- |
| 大运十年为主，流年一年为辅，三层叠读 | 重流年引动——流年与大运、原局形成刑冲合害时才应事 |
| 重视"大运定十年基调" | 重视"流年引动具体象" |

**项目口径**：按子平三层叠读（见[起运大运流年](/learn/bazi-luck-cycles)）。

## 三 · 如何取舍

| 场景 | 推荐口径 | 理由 |
| --- | --- | --- |
| 学系统框架 | 子平派 | 书本传承完整，从概念到判断链条清晰 |
| 实战断盘 | 子平 + 盲派双修 | 子平定框架，盲派直给应事 |
| 查调候用神 | 子平调候派 | 穷通宝鉴是调候最权威著作 |
| 想快速入门 | 新派简化版 | 但要注意简化版省略了关键边界 |
| 看自己盘 | 先子平走一遍，再用盲派口诀印证 | 不混用 |

**关键原则：一张盘只走一套口径，不要混用。** 混用就像同时用公制和英制——结果一定错。
