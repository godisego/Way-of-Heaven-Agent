# 阴阳五行入门：先学分类与关系

先修：[命理大局观](/learn/bazi-overview)。本课属于七层地图的第一层。目标是认识阴阳分类，写对五行相生、相克两条链，并说明它们在课程中是传统符号规则。

## 一 · 阴阳怎样使用

阴阳用于描述对待关系，例如明暗、动静、内外。它依赖观察语境，不是给人贴好坏标签；命理表中天干的阴阳则是固定约定。

| 示例语境 | 阳 | 阴 |
| --- | --- | --- |
| 明暗 | 明 | 暗 |
| 动静 | 动、外展 | 静、内敛 |
| 天干 | 甲丙戊庚壬 | 乙丁己辛癸 |

这些对应帮助理解传统语言，不是把一个人的性格或能力二分。阴阳在其他传统学科中的人体对应，也不能作为本课程的健康判断依据。

## 二 · 五行是什么

木、火、土、金、水是传统分类范畴，兼有物象与功能的象征解释。入门可以用下面的记忆表，但不要据此推导现代物理机制。

| 五行 | 常用物象 | 常见象征语言 | 命理季节对应 |
| --- | --- | --- | --- |
| 木 | 树木 | 生长、舒展 | 春 |
| 火 | 火焰 | 炎上、温暖 | 夏 |
| 土 | 大地 | 承载、转化 | 四季末月等土月语境 |
| 金 | 金属 | 收敛、肃杀 | 秋 |
| 水 | 水流 | 润下、流动 | 冬 |

“土对应长夏”是另一种常见五行表述；八字还要落到辰戌丑未等具体月令，不能把不同用途的表直接合并。后续强弱判断也不能只数五个字出现几次。

## 三 · 先掌握两种基本关系

```wuxing
```

**相生：木 → 火 → 土 → 金 → 水 → 木。**

**相克：木 → 土 → 水 → 火 → 金 → 木。**

两条链是本课程的换算基础。相生不等于现实里一定有利，相克也不等于一定有害。传统解释还会讨论乘、侮、制化等扩展，本课先学基本表，不把“只讲两种”误写成全部传统关系只有两种。

举例：木生火，所以甲木见丙火属于“我生”；火克金，所以丙火见庚金属于“我克”。加入阴阳后，才能进一步命名十神。

## 四 · 它怎样进入八字

给定出生日期和时间，按选定历法口径换算四柱；为天干地支查阴阳五行表；以日干为参照计算生克；随后作者才引入格局、旺衰等解释。

```text
日期与设置 → 四柱 → 阴阳五行查表 → 关系换算 → 带条件的传统解释
```

前几步可以检查计算是否一致。最后一步若声称能判断现实人格或事件，需要另外的证据。“出生在春天，所以某种人格力量天生更强”不能当作已证实事实教授。

## 五 · 练习与参考答案

1. 木生什么、克什么？生火、克土。
2. 水生什么、克什么？生木、克火。
3. 甲木见丙火为什么不能只凭“木生火”定食神？还要检查阴阳；甲丙同为阳，本课定义为食神，甲丁异阴阳为伤官。
4. “相克就是坏事”是否成立？不成立；它首先是关系名称，现实判断不能由关系名直接推出。
