# 阅读说明

《阴符经》全名《黄帝阴符经》，全文仅三百余字，属道教重要经典，历代注家极多、解读分歧也极大。本文取经文全文（公版），按通行上中下三篇分段，配以原创的现代解读，取其"观天道以执人事"的方法论骨架，不涉丹道与符咒的专门内容。

经文行文极简而意象陡峭，同一段文字历来有多种读法。本文只提供一条面向决策与自省的实践路径。

# 上篇：观天之道，执天之行

"观天之道，执天之行，尽矣。故天有五贼，见之者昌。五贼在乎心，施行于天。宇宙在乎手，万化生乎身。"

又："天性人也，人心机也。立天之道，以定人也。"

开篇十二字就是全部纲领：先观察规律（观天之道），再按规律行事（执天之行）。"五贼"历来注解为五行相克之机——金木水火土互相成就又互相克制的关系。翻译成系统语言：任何系统里都存在互相牵制的五股力量，看清它们如何互偷互生的人，才谈得上驾驭局面。"立天之道，以定人也"给了一个次序：先弄清不可更改的规律，再安顿人的安排——与"先认识对象的结构，再谈改造"是同一件事。

# 上篇续：天发杀机，移星易宿

"天发杀机，移星易宿；地发杀机，龙蛇起陆；人发杀机，天地反覆；天人合发，万化定基。"

又："性有巧拙，可以伏藏。九窍之邪，在乎三要，可以动静。"

"杀机"不是凶残，而是引动巨变的临界点：星宿移位、龙蛇出蛰、人事翻覆，都始于某个临界被触碰。识别系统里"快要压不住的那个点"，比事后应对更有价值。"性有巧拙，可以伏藏"则讲藏露的分寸：机巧与拙朴都是禀性，什么时候收、什么时候放，决定你是工具还是主人。

# 中篇：天生天杀，道之理也

"天生天杀，道之理也。天地，万物之盗；万物，人之盗；人，万物之盗。三盗既宜，三才既安。"

又："故曰：食其时，百骸理；动其机，万化安。"

这一段用"盗"字讲万物的相互依存与相互取用：天地取用于万物，万物取用于人，人取用于万物——取用有度（三盗既宜），系统才安。这是最早的资源可持续命题。"食其时"三个字最平实也最难：按时进食、按时作息、在该收获的时节收获、在该休耕的土地上休耕。现代对应物是：现金流按时、精力按节律、项目按窗口，错时强取皆为盗之不正。

# 中篇续：人知其神之神，不知不神之所以神

"人知其神而神，不知不神之所以神也。日月有数，大小有定，圣功生焉，神明出焉。其盗机也，天下莫能见，莫能知。君子得之固躬，小人得之轻命。"

众人惊叹显性的神奇，看不见"不神之神"——那些朴素到不起眼的规律才是真正的引擎：日月有数、大小有定，把日历与刻度做扎实，神奇自然涌现。这是对"追风口、拜天才"思维的最早反诘。"君子得之固躬，小人得之轻命"则是知识伦理：同一套规律，有人用来修身固本，有人用来投机赌命——工具不背这个锅。

# 下篇：瞽者善听，聋者善视

"瞽者善听，聋者善视。绝利一源，用师十倍；三反昼夜，用师万倍。"

又："心生于物，死于物，机在目。"

缺失反而造就专长：瞎子听力过人，因为全部感知集中在一个源头。"绝利一源"是极狠的减法——关掉一个信息源/欲望源，效能成倍；能持续做三轮（三反昼夜）这种关停，效能在万倍量级。现代版本：砍掉同时并行的第二个项目，退掉只会消耗注意力的群，锁掉一天里最耗神的那个应用。注意力在哪里，机就在哪里。

# 下篇续：恩生于害，害生于恩

"恩生于害，害生于恩。……愚人以天地文理圣，我以时物文理哲。"

恩害互生是全书最冷峻的洞见：溺爱是害的种子，严苛里可能长出感恩；对团队、对子女、对自己皆然。检查自己正享受的"恩"里埋着什么，检查自己正抱怨的"害"里养着什么，比趋吉避凶的算计更根本。

末段"愚人以天地文理圣，我以时物文理哲"点明方法论：别人从玄远的天象里求圣意，我从眼前时事的变化里求判断——把仰望收回到观察，把神秘收回到时务。这也正是三百余字《阴符经》留给现代决策者最实在的一句。
