# 阅读说明

本文按《庄子》内七篇的篇目整理行动主题。古文短句属公版经典，其余故事与思想均用现代汉语概括，不是任何现代译注本的摘录。《庄子》善用寓言和反辽，同一段文字常有多种解法，本文只提供一条实践路径。

这些篇章不是教人放弃技艺、关系和责任，而是检查：我是否把局部尺度当成了全部世界，是否在用过度的意志阻塞自然的变化。

# 《逍遥游》：先问凭借什么

鲲鹏、蜩与学鸠的寓言，展示了不同生命尺度与视野。小尺度不必低劣，但用自己的航程否定别人的风程，就会把局限当成真理。篇中说鹏高飞仍“有所待”，意味着宏大自由也有条件。

行动前可盘点自己的“所待”：身体、技能、时间、平台、他人信任和自然环境。承认凭借不会减少成就，反而能防止把条件当成个人全能，也能提醒自己维护那些承载飞行的风。

# 《齐物论》：别让立场冒充整体

《齐物论》反复摇动成见、语言与彼此的界线。“彼亦一是非，此亦一是非”不是说事实不可判断，而是说彼此都容易把从自己位置看到的是非，当成不需要交代位置的绝对结论。

遇到僵局时，把双方的话各改写为三层：可核验的事实，从某个位置得出的解释，希望保护的价值。事实层可以求真，解释层可以互换视角，价值层则可以谈边界和取舍。

# 《养生主》：庖丁解牛与依理而行

庖丁的刀不是靠更大力气穿过骨头，而是依照牛体本有的间隙运行。技艺初成时眼中是整牛，熟练后感知的是结构与空隙。但遇到筋骨盘结处，他仍会警惕、放慢、凝神。

“依乎天理，因其固然”可以转为三个动作：先认识对象的结构，寻找阻力最小的交界，在异常处主动慢下来。真正的熟练不是不思考，而是把注意力留给不同于往常的部分。

# 《人间世》：心斋与危险环境

《人间世》关心人如何进入复杂且有风险的政治和人际环境。颜回的“心斋”要求放下预设的成功剧本，不让自我表演占满感知。心斋不是失去判断，而是让现实先能进来。

本篇也有“无用之用”的故事：一棵不合木匠标准的大树，因不被砍伐而得以尽其天年。这不是说人应当故意无能，而是提醒人：外部的单一用途不能穷尽生命价值，有时拒绝被一种用法耗尽，才能保住更长的可能。

# 《德充符》：不以外形穷尽一个人

《德充符》塑造了多位身体有缺损而德性完整的人物，试图打断外在形貌、社会身份与人格价值之间的自动等号。所谓“才全而德不形”，将注意从可见的表演移向不必宣示的内在稳定。

在现实中，不以某一特征穷尽一个人：疾病、残障、失业、一次失败或一个头衔，都是真实条件，但不是整个人。给建议时既不忽略条件，也不把条件写成本质判决。

# 《大宗师》：变化、丧失与安时处顺

《大宗师》用大量关于生死和变化的故事，将人放回更大的化迁中。子桑户死后，朋友鼓琴而歌；子舆身体变形，仍想象造化将如何使用自己。这些寓言不要求人没有悲伤，而是不把变化完全当成对自我的冒犯。

“安时而处顺”不是面对可避免的伤害也不行动。它首先要区分：哪些是此刻必须承受的事实，哪些仍是可以改变的条件。对前者不再额外反抗，对后者不借顺应之名放弃责任。

# 《应帝王》：不要把好意变成凿七窍

篇末的混沌寓言说，儆与忽为了报答混沌，想让他像常人一样有七窍，于是每日凿一窍，七日而混沌死。善意如果以自己的标准为唯一范本，就可能把不同当成缺陷，把帮助变成改造。

提供帮助前，先问对方想保留什么、希望改变什么，以及他是需要倾听、信息还是共同行动。不经询问就开始“为你好”，很容易凿开对方并不需要的窍。

# 《逍遥游》原文选读：小知不及大知

"北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。……鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里，去以六月息者也。"

又："蜩与学鸠笑之曰：'我决起而飞，抢榆枋而止，时则不至，而控于地而已矣，奚以之九万里而南为？'"

又："且夫水之积也不厚，则其负大舟也无力。……风之积也不厚，则其负大翼也无力。故九万里，则风斯在下矣。"

按：鹏并非嘲笑蜩的对象，庄子同时写鹏"犹有所待"——风积不厚则大翼无力。真正的高下不在大小，在"所待"的结构：想飞多高，就要多厚的风。置换成事业语言：你想接多大的事，先看承载你的水面有多深。

# 《齐物论》原文选读：吾丧我与两行

"南郭子綦隐机而坐，仰天而嘘，答焉似丧其耦。……子綦曰：'偃，不亦善乎，而问之也！今者吾丧我，汝知之乎？'"

又："方生方死，方死方生；方可方不可，方不可方可。……是以圣人和之以是非而休乎天钧，是之谓两行。"

又："狙公赋芧，曰：'朝三而暮四。'众狙皆怒。曰：'然则朝四而暮三。'众狙皆悦。名实未亏而喜怒为用，亦因是也。"

按："吾丧我"是与角色化的自我拉开距离——那个急于辩护、急于胜出的"我"，未必是全部的你。朝三暮四的寓言讽刺的是被表述顺序牵着走的情绪：总数没变，框架变了，喜怒就变了。谈判与汇报里，先看清对方的"朝三暮四"，也检视自己的。

# 《养生主》原文选读：庖丁解牛

"庖丁为文惠君解牛，手之所触，肩之所倚，足之所履，膝之所踦，砉然向然，奏刀騞然，莫不中音。……庖丁释刀对曰：'臣之所好者道也，进乎技矣。始臣之解牛之时，所见无非牛者。三年之后，未尝见全牛也。方今之时，臣以神遇而不以目视，官知止而神欲行。依乎天理，批大郤，导大窾，因其固然。'"

又："每至于族，吾见其难为，怵然为戒，视为止，行为迟。动刀甚微，謋然已解，如土委地。……得养生焉。"

又："指穷于为薪，火传也，不知其尽也。"

按：三个可迁移的动作都在原文里——"所见无非全牛"是新手期，"未尝见全牛"是看见结构期，"怵然为戒"是遇到筋结处反而放慢。最后的"薪尽火传"把话题从技艺引向传承：个体的柴会烧完，让火种传下去才是养生的完成。

# 《人间世》原文选读：心斋

"回曰：'敢问心斋。'仲尼曰：'若一志，无听之以耳而听之以心，无听之以心而听之以气。听止于耳，心止于符。气也者，虚而待物者也。唯道集虚。虚者，心斋也。'"

又："绝迹易，无行地难。为人使易以伪，为天使难以伪。"

按：心斋是给感知腾出空位——满脑子剧本的人听不见对方真正在说什么。"虚而待物"可操作化为：重要谈话前，把自己预写的台词划掉一半，留白给意外。不预设剧本的人最难被表演欺骗。

# 《大宗师》原文选读：坐忘与安时处顺

"颜回曰：'回益矣。'仲尼曰：'何谓也？'曰：'回忘仁义矣。'曰：'可矣，犹未也。'复见，曰：'回忘礼乐矣。'曰：'可矣，犹未也。'他日复见，曰：'回坐忘矣。'仲尼蹴然曰：'何谓坐忘？'颜回曰：'堕肢体，黜聪明，离形去知，同于大通，此谓坐忘。'"

又："若人之形者，万化而未始有极也，其为乐可胜计邪？……故圣人将游于物之所不得遁而皆存。"

又："安时而处顺，哀乐不能入也，古者谓是帝之县解。"

按：坐忘是逐层放下——先放下教条（仁义），再放下形式（礼乐），最后放下对自我形躯与聪明的执着。"县解"（悬解）是把倒吊的自己放下来：很多痛苦不在事情本身，在"必须按我的剧本"这根绳子。

# 《应帝王》原文选读：浑沌之死

"南海之帝为儵，北海之帝为忽，中央之帝为浑沌。儵与忽时相与遇于浑沌之地，浑沌待之甚善。儵与忽谋报浑沌之德，曰：'人皆有七窍，以视听食息，此独无有，尝试凿之。'日凿一窍，七日而浑沌死。"

按：全书的收尾寓言，也是最锋利的一则管理寓言。儵与忽的动机是善的（报德），方法是标准化的（人人皆有七窍），结果是毁灭。任何"为你好"的改造——教育、管理、产品、亲密关系——在动手前都应过一遍这个问题：我要凿的这个窍，是他缺的，还是我有的？
