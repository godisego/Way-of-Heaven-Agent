# 阅读说明

本文按《庄子》内七篇的篇目整理行动主题。古文短句属公版经典，其余故事与思想均用现代汉语概括，不是任何现代译注本的摘录。《庄子》善用寓言和反辽，同一段文字常有多种解法，本文只提供一条实践路径。

这些篇章不是教人放弃技艺、关系和责任，而是检查：我是否把局部尺度当成了全部世界，是否在用过度的意志阻塞自然的变化。

# 《逍遥游》：先问凭借什么

鲲鹏、蜩与学鸠的寓言，展示了不同生命尺度与视野。小尺度不必低劣，但用自己的航程否定别人的风程，就会把局限当成真理。篇中说鹏高飞仍“有所待”，意味着宏大自由也有条件。

行动前可盘点自己的“所待”：身体、技能、时间、平台、他人信任和自然环境。承认凭借不会减少成就，反而能防止把条件当成个人全能，也能提醒自己维护那些承载飞行的风。

# 《齐物论》：别让立场冒充整体

《齐物论》反复摇动成见、语言与彼此的界线。“彼亦一是非，此亦一是非”不是说事实不可判断，而是说彼此都容易把从自己位置看到的是非，当成不需要交代位置的绝对结论。

遇到僵局时，把双方的话各改写为三层：可核验的事实，从某个位置得出的解释，希望保护的价值。事实层可以求真，解释层可以互换视角，价值层则可以谈边界和取舍。

# 《养生主》：庖丁解牛与依理而行

庖丁的刀不是靠更大力气穿过骨头，而是依照牛体本有的间隙运行。技艺初成时眼中是整牛，熟练后感知的是结构与空隙。但遇到筋骨盘结处，他仍会警惕、放慢、凝神。

“依乎天理，因其固然”可以转为三个动作：先认识对象的结构，寻找阻力最小的交界，在异常处主动慢下来。真正的熟练不是不思考，而是把注意力留给不同于往常的部分。

# 《人间世》：心斋与危险环境

《人间世》关心人如何进入复杂且有风险的政治和人际环境。颜回的“心斋”要求放下预设的成功剧本，不让自我表演占满感知。心斋不是失去判断，而是让现实先能进来。

本篇也有“无用之用”的故事：一棵不合木匠标准的大树，因不被砍伐而得以尽其天年。这不是说人应当故意无能，而是提醒人：外部的单一用途不能穷尽生命价值，有时拒绝被一种用法耗尽，才能保住更长的可能。

# 《德充符》：不以外形穷尽一个人

《德充符》塑造了多位身体有缺损而德性完整的人物，试图打断外在形貌、社会身份与人格价值之间的自动等号。所谓“才全而德不形”，将注意从可见的表演移向不必宣示的内在稳定。

在现实中，不以某一特征穷尽一个人：疾病、残障、失业、一次失败或一个头衔，都是真实条件，但不是整个人。给建议时既不忽略条件，也不把条件写成本质判决。

# 《大宗师》：变化、丧失与安时处顺

《大宗师》用大量关于生死和变化的故事，将人放回更大的化迁中。子桑户死后，朋友鼓琴而歌；子舆身体变形，仍想象造化将如何使用自己。这些寓言不要求人没有悲伤，而是不把变化完全当成对自我的冒犯。

“安时而处顺”不是面对可避免的伤害也不行动。它首先要区分：哪些是此刻必须承受的事实，哪些仍是可以改变的条件。对前者不再额外反抗，对后者不借顺应之名放弃责任。

# 《应帝王》：不要把好意变成凿七窍

篇末的混沌寓言说，儆与忽为了报答混沌，想让他像常人一样有七窍，于是每日凿一窍，七日而混沌死。善意如果以自己的标准为唯一范本，就可能把不同当成缺陷，把帮助变成改造。

提供帮助前，先问对方想保留什么、希望改变什么，以及他是需要倾听、信息还是共同行动。不经询问就开始“为你好”，很容易凿开对方并不需要的窍。
