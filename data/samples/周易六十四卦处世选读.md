# 阅读说明

本文选取《周易》经文和《易传》中常用于处世判断的句子，原文属公版古籍。解读是原创整理，重点在局势、时机与人事，不把卦象当作确定预言。古籍版本字句偶有差异，引用时应以所用底本复核。

卦的价值，可以理解为“把复杂局面压缩成可讨论的关系”。先辨所处之时，再看位置、应对与转化，比单独追问“吉还是凶”更有用。

# 乾坤：进取与承载

《乾·象》：“天行健，君子以自强不息。”《坤·象》：“地势坤，君子以厚德载物。”

乾与坤不是两种人设，而是一件事的两种能力。进取需要持续和创造，承载需要容量和配合。只会进而不能承载，成果会散；只会承载而不发起，局面会滞。

用在人事上，可以分别追问：我要主动推进的一步是什么？为了让它落地，需要承载哪些细节、他人和后果？

# 屯与蒙：开始时不求顺滑

《屯》卦辞有“勿用有攸往，利建侯”；《蒙》卦辞说“匪我求童蒙，童蒙求我”。

屯是初生的困难：资源、规则和配合都未就位。此时不宜把愿景当进度，而应先建立责任与秩序。蒙讲学习的姿态：问题必须由学习者真正提出，反复轻慢地求答，只会把教导消耗成代替思考。

新局面的动作是：先定负责人和一个可检验的小目标；先把问题写清，再求教。

# 需与讼：等待与争议

《需·彖》说“需，须也；险在前也”。《讼》卦辞说“有孚，窒惕，中吉，终凶。利见大人，不利涉大川。”

需不是拖延，而是前方有险时不以焦虑代替条件。等待期要补给养、信用和准备。讼提醒争议即使理由真实，追到底也可能伤害整体。能在事实澄清、边界建立和公正裁判处停下，比“必须彻底赢”更可持续。

判断是等还是拖，看等待期是否在增加条件。判断是争还是停，看继续争论能否产生新的事实或保护必要边界。

# 谦：有功而不自满

《谦》卦辞：“谦，亨，君子有终。”《象》说：“裒多益寡，称物平施。”

谦不是否认能力，而是不让已有成果封闭修正空间。一个系统中某处过满、某处不足，谦的动作就是调节：把资源、注意和权力送到真正稀缺的地方。

实务上，做完一件事后同时记录“哪里做对”和“哪个条件不属于我”，可以既不虚假贬低自己，也不把偶然当成全能。

# 损益：加减要看流向

《损·彖》说“损下益上，其道上行”；《益·彖》说“损上益下，民说无疆”。

“损”未必是坏，“益”也未必是好，要看谁在付出、谁在得益，以及这个流向能否持续。创业初期削减舒适换取共同能力，可以是有意义的损；长期让基层耗损而顶层增益，则会伤根。

决策时不只写“收益”，还要写一列“成本最终落在谁身上”。这一列常能暴露被口号遮住的局势。

# 困与井：困境中先保持来源

《困》卦辞有“有言不信”；《井》卦辞说“改邑不改井，无丧无得，往来井井”。

困时语言的信用下降，说得越满越可能显得无力。此时先守住可验证的小行动，少作宏大承诺。井是稳定供给的比喻：环境可变，持续滋养人的基础来源不可荒废。

困境中可先盘点三口“井”：身体的基本节律、能说真话的关系、能重复产生价值的技能。先保住井，再谈突围。

# 革鼎与未济：变革后还要安顿

《革》卦辞说“己日乃孚”；《鼎·象》说“君子以正位凝命”。《未济》卦辞有“小狐汔济，濡其尾，无攸利”。

改革需要理由成熟、信用累积，不是只靠不满。旧制已破之后，鼎所象征的位置、职责与新秩序必须随之建立。未济放在全书之末，提醒人不要在快到岸时放松警惕。

对变革的完整检查是：为什么现在可信？旧物破除后谁负责新秩序？在最后十分钟最容易漏掉什么？
