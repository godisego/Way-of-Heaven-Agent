# 阅读说明

本文选取《周易》经文和《易传》中常用于处世判断的句子，原文属公版古籍。解读是原创整理，重点在局势、时机与人事，不把卦象当作确定预言。古籍版本字句偶有差异，引用时应以所用底本复核。

卦的价值，可以理解为“把复杂局面压缩成可讨论的关系”。先辨所处之时，再看位置、应对与转化，比单独追问“吉还是凶”更有用。

# 乾坤：进取与承载

《乾·象》：“天行健，君子以自强不息。”《坤·象》：“地势坤，君子以厚德载物。”

乾与坤不是两种人设，而是一件事的两种能力。进取需要持续和创造，承载需要容量和配合。只会进而不能承载，成果会散；只会承载而不发起，局面会滞。

用在人事上，可以分别追问：我要主动推进的一步是什么？为了让它落地，需要承载哪些细节、他人和后果？

# 屯与蒙：开始时不求顺滑

《屯》卦辞有“勿用有攸往，利建侯”；《蒙》卦辞说“匪我求童蒙，童蒙求我”。

屯是初生的困难：资源、规则和配合都未就位。此时不宜把愿景当进度，而应先建立责任与秩序。蒙讲学习的姿态：问题必须由学习者真正提出，反复轻慢地求答，只会把教导消耗成代替思考。

新局面的动作是：先定负责人和一个可检验的小目标；先把问题写清，再求教。

# 需与讼：等待与争议

《需·彖》说“需，须也；险在前也”。《讼》卦辞说“有孚，窒惕，中吉，终凶。利见大人，不利涉大川。”

需不是拖延，而是前方有险时不以焦虑代替条件。等待期要补给养、信用和准备。讼提醒争议即使理由真实，追到底也可能伤害整体。能在事实澄清、边界建立和公正裁判处停下，比“必须彻底赢”更可持续。

判断是等还是拖，看等待期是否在增加条件。判断是争还是停，看继续争论能否产生新的事实或保护必要边界。

# 谦：有功而不自满

《谦》卦辞：“谦，亨，君子有终。”《象》说：“裒多益寡，称物平施。”

谦不是否认能力，而是不让已有成果封闭修正空间。一个系统中某处过满、某处不足，谦的动作就是调节：把资源、注意和权力送到真正稀缺的地方。

实务上，做完一件事后同时记录“哪里做对”和“哪个条件不属于我”，可以既不虚假贬低自己，也不把偶然当成全能。

# 损益：加减要看流向

《损·彖》说“损下益上，其道上行”；《益·彖》说“损上益下，民说无疆”。

“损”未必是坏，“益”也未必是好，要看谁在付出、谁在得益，以及这个流向能否持续。创业初期削减舒适换取共同能力，可以是有意义的损；长期让基层耗损而顶层增益，则会伤根。

决策时不只写“收益”，还要写一列“成本最终落在谁身上”。这一列常能暴露被口号遮住的局势。

# 困与井：困境中先保持来源

《困》卦辞有“有言不信”；《井》卦辞说“改邑不改井，无丧无得，往来井井”。

困时语言的信用下降，说得越满越可能显得无力。此时先守住可验证的小行动，少作宏大承诺。井是稳定供给的比喻：环境可变，持续滋养人的基础来源不可荒废。

困境中可先盘点三口“井”：身体的基本节律、能说真话的关系、能重复产生价值的技能。先保住井，再谈突围。

# 革鼎与未济：变革后还要安顿

《革》卦辞说“己日乃孚”；《鼎·象》说“君子以正位凝命”。《未济》卦辞有“小狐汔济，濡其尾，无攸利”。

改革需要理由成熟、信用累积，不是只靠不满。旧制已破之后，鼎所象征的位置、职责与新秩序必须随之建立。未济放在全书之末，提醒人不要在快到岸时放松警惕。

对变革的完整检查是：为什么现在可信？旧物破除后谁负责新秩序？在最后十分钟最容易漏掉什么？

# 师与比：竞争与结盟

《师》卦辞："师，贞，丈人吉，无咎。"《象》曰："地中有水，师；君子以容民畜众。"《比》卦辞："比，吉。原筮，元永贞，无咎。不宁方来，后夫凶。"

师讲以纪律承载实力：力量本身不决定吉凶，谁执掌、为何而用才决定。比讲结盟要早要诚：等局面明朗才赶来靠拢的"后夫"，往往已经失去被信任的位置。

组队或竞争前可问三句：我们这支"师"由什么人执掌纪律？结盟是在互相增加选项，还是互相绑定退路？我是先来守信的同盟，还是观望的"后夫"？

# 泰与否：顺境与堵塞互为门

《泰》卦辞："泰，小往大来，吉亨。"《彖》曰："天地交而万物通也。"《否》卦辞："否之匪人，不利君子贞，大往小来。"《彖》曰："天地不交而万物不通也。"

泰与否的分别不在资源多少，而在流通是否顺畅：上下沟通、供需匹配、人尽其用即泰；各自封闭、信息滞塞、能者无用武之地即否。泰卦九三已警示"无平不陂，无往不复"——顺境里就要为周期做准备。

顺境中检查：谁的话最近传不到决策桌？逆境中检查：哪一条沟通渠道先恢复了，局面就从哪里开始回暖。

# 同人与大有：先聚人再聚物

《同人》卦辞："同人于野，亨。利涉大川。"《大有·象》曰："火在天上，大有；君子以遏恶扬善，顺天休命。"

同人在野，讲在远离小圈子的开阔处找共识，同盟才足够大；大有讲富足之后的治理——遏恶扬善，让拥有配得上责任。资源向一个人聚集时，分配的公信力比资源本身更稀缺。

盘点"大有"可问：我拥有的是暂时的位置，还是可复用的能力与信用？分享规则是否先于下一次分配而存在？

# 随与蛊：跟随与整饬

《随》卦辞："随，元亨利贞，无咎。"《蛊·象》曰："山下有风，蛊；君子以振民育德。"

随讲顺势跟从要看所随之人：随谁，就是在选未来的自己。蛊讲积弊——表面安稳的东西内部已经发酵，需要主动整饬而非掩盖。山下风滞，正是要动手疏通的信号。

接手任何旧局面，先做一次"蛊"的盘点：哪些规矩已经没人真信？哪些账目经不起细看？整饬宜早宜实，捂到发臭代价更大。

# 临与观：走近与退看

《临·象》曰："泽上有地，临；君子以教思无穷，容保民无疆。"《观·象》曰："风行地上，观；先王以省方观民设教。"

临是走到近处亲自照看，观是退到远处看全局与他人的反应。只近不远会溺于细节，只远不近会脱于实际。管理节奏可以在两态间轮换：季初临，季末观。

自查：我对这件事最近一次"临"是什么时候？"观"的时候，我看的是数据还是面子的反应？

# 复与无妄：回头与守正

《复·象》曰："雷在地中，复；先王以至日闭关，商旅不行，后不省方。"《无妄》卦辞："无妄，元亨利贞。其匪正有眚，不利有攸往。"

复讲力量在低谷中悄悄回萌——冬至一阳生，宜养不宜耗。无妄讲守正则通，妄动则有灾：不是不许动，而是不可带妄念动。回升期最忌把休养的力量立刻押上孤注。

低谷里先问：这一阳生在何处？回升时再问：这一步的动机是事实所需，还是急于证明自己？

# 坎与离：险中守信与附丽于明

《坎》卦辞："习坎，有孚，维心亨，行有尚。"《离·彖》曰："离，丽也；日月丽乎天，百谷草木丽乎土。"

坎是重叠的险：出险不靠豪赌，靠信用与心志的持续——有孚维心亨。离是依附与光明：火必须附在薪上，才华必须附在可持续的载体上，脱离所附则灭。

身处险时可清点：别人凭什么继续信我？春风得意时可清点：我附着的"薪"是什么，烧完了接什么？

# 遁与大壮：该退的退，该长的长

《遁·象》曰："天下有山，遁；君子以远小人，不恶而严。"《大壮·象》曰："雷在天上，大壮；君子以非礼弗履。"

遁不是逃跑，而是不与消耗性的人和局缠斗——保持距离而不失体度。大壮是力量正盛，此时最容易以力越界，所以配的是"非礼弗履"：越有力，越要守规矩。

面对纠缠可问：这是需要解决的冲突，还是应当保持距离的消耗？力量上升期给自己立一条：哪三件事力量再大也不做？

# 晋与明夷：晋升与晦藏

《晋·象》曰："明出地上，晋；君子以自昭明德。"《明夷·象》曰："明入地中，明夷；君子以莅众，用晦而明。"

晋是日出地上，路径是把自己的德能显明出来，而不是挤进光的圈子。明夷是光入地下——环境昏暗时，智者外晦内明：不炫耀判断，不放弃判断。

遭遇不明朗的时期，可把目标从"被看见"调整为"保持可被看见的能力"：手艺不停、记录不断、底线不松。

# 蹇与解：难行与纾解

《蹇·象》曰："山上有水，蹇；君子以反身修德。"《解·象》曰："雷雨作，解；君子以赦过宥罪。"

蹇是前有险、后有阻，此时最有效的动作往往不在前方，而在反身：补自己的短板、修被忽略的关系。解是雷雨后郁结散开，宜宽不宜急：赦小过、宥无心之失，让系统能重新流动。

长期僵局自查：我一直在往前撞，还是回头查过"反身"清单？僵局刚松动时，第一条恢复的是宽，不是清算。

# 夬与姤：决断与不期而遇

《夬·象》曰："泽上于天，夬；君子以施禄及下，居德则忌。"《姤·象》曰："天下有风，姤；后以施命诰四方。"

夬是力量足以决去积弊，但卦辞警告"不利即戎"——决断靠势与理，不靠意气；且要"告自邑"：先安内，再对外。姤是不期而遇，风行天下，微小的相遇可能改变大局，不可轻慢任何初始条件。

下决断前检查：我有"告自邑"的内部共识吗？遇到意外的人与事，先别定性为干扰——记录它，三天后再判断。

# 既济与未济：完成与未完成

《既济·象》曰："水在火上，既济；君子以思患而豫防之。"《未济·象》曰："火在水上，未济；君子以慎辨物居方。"

既济是事已成，恰在此时要防"初吉终乱"：完成的第二天就要列维护清单。未济是事未成，全书以此收尾—— processes永远比终点长，慎辨物、居各方，让每样东西回到合适的位置。

项目交付后问：谁在维护？长期未决的事问：是条件未备，还是东西放错了位置？
