# 阅读说明

这是一份斯多葛主义实践笔记，主要依据爱比克泰德《手册》《论说集》、马可·奥勒留《沉思录》和塞涅卡书信中的核心练习。文中以现代汉语概括和转述，不是任何一种中译本的原文。

斯多葛练习不是压抑情绪，也不是对不公麻木。它试图区分判断与事实，把精力放回德性、意图和行动。

# 可控与不可控

直接属于我的，是判断、愿望、拒绝、意图以及此刻的行动。不完全属于我的，是身体结果、财富、名声、职位、别人的反应和外部事件。这不是说后一类与我无关，而是说它们需要我参与，却不服从我的意志。

可控圈不是大小问题，而是性质问题。一场重要面试的结果不可控，准备时是否诚实、回答时是否清楚则可控。把不可控的结果当作唯一评价，心就会被外界牵走。

# 事实、印象与判断

事件来临时，心中会先出现一个印象：“他看不起我”、“这次完了”。斯多葛练习要求暂停同意这个印象，先把可观察的事实写出来：“他没有回复消息”、“项目没有按期通过”。

暂停不等于宣布所有解释都是错的。它只是把“我想到了什么”与“已经证明了什么”分开，为更准确的判断留出时间。

# 保留条款：尽力而不索取结果

对每一个外部目标，可以在心里加上保留条款：“我将尽力完成它，如果现实条件允许。”保留条款不降低投入，只取消了一个虚假契约：仿佛只要我够努力，世界就欠我一个特定结果。

一个弓手要把站姿、呼吸和放弦做好，箭离弦后的风却不再完全属于他。评价弓手时，应先看他如何射，不是只看箭最后落在哪里。

# 预想失去与感恩

预想失去不是反复灾难化，而是承认人、物与条件都是暂时托付。短暂想象某个便利不存在，可以让人重新看见它平时的价值。练习的终点是珍惜和准备，不是恐惧。

如果预想让焦虑升高，就缩小尺度：不想极端灾难，只想今天断网两小时、一次计划取消，然后写下备用方案。没有应对行动的灾难想象，往往只是焦虑的燃料。

# 从上方看与共同人性

“从上方看”是把自己的烦恼放进更大的时间和空间尺度。它不是说个人痛苦不重要，而是防止当下的一次受挫冒充为整个世界。

斯多葛伦理把人看作共同体成员。因此，平静不是撤回对他人的责任。恰恰因为不把虚荣、报复或掌声当成最高的好，人才更能按公正、节制、勇气和智慧行动。

# 晨间与夜间复盘

早上写三行：今天哪个结果不由我保证？哪个品质由我保持？遇到阻力时，我的下一个可控动作是什么？

晚上不做自我审判，只做事实复盘：哪一刻我把印象当成了事实？哪一件事尽到了本分？明天要重做的一个小动作是什么？复盘的目的是训练判断，不是为羞耻增加新证据。

# 爱比克泰德《手册》第一条意译

原文大意为：有些事在我们权能之内，有些不在。权能之内的是意见、冲动、欲望与厌恶——一句话，我们自己的作为；不在权能之内的是身体、财产、名声与职位——一句话，不属于我们自己作为的东西。权能内的事自然自由、不受阻碍；权能外的事脆弱、受制于人。

补上常被漏掉的后半段：如果你把只属于前者的事当作善，把后者当作恶，你就必然被牵制、怨怼与不安追着走。这份清单不是教人冷漠，而是一张精力分配表——把最好的注意力，付给唯一真正服从你的那个领域。

# 马可·奥勒留《沉思录》意译：清晨预备与障碍即路

清晨预备的大意是：今天我会遇到多管闲事的人、忘恩的人、傲慢的人——他们如此，是因为分不清善恶。我不能恨他们，因为我们都共享理性而生；我也不能因他们而偏离自己的路。

另一则常被引用的大意：路上的障碍本身就是路；挡路的东西，可以变成它的材料。项目受阻时的对应动作是：把"取消这次机会"改写为"这次机会换了形状"，再问新形状需要什么材料。

# 塞涅卡书信意译：预演灾祸与最坏的一天

塞涅卡建议的预演不是焦虑的循环播放，而是一次正式的推演：设想失去所珍视之物的那一天，现在就练习告诉自己"这不是必然，但它可能"。推演之后要做的不是囤积恐惧，而是更新清单——如果失去，我还剩下什么可以重建？

他还有一条关于时间的忠告大意是：没有人把财物交给陌生人保管，却人人把时间随手交出去——而时间恰恰是唯一无法赎回的资产。把"最近把时间都给了谁"写进周复盘，是现代版的塞涅卡审问。

# 斯多葛的留白：不评价的命运

斯多葛并不要求人对一切发生无感。它练习的是延迟评价：事件先于故事。"我失业了"是事件；"我完了"是故事。故事里往往混着事实与未经验证的判决。

留白的位置，就是事件与故事之间的那条缝。人在那条缝里才真正有自由——这也是斯多葛与存在主义罕见地握手的时刻：两者都相信，在人不得不承受的东西之外，始终有一个小小的、不可让渡的回应空间。
