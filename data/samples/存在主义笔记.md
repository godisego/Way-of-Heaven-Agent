# 自由与选择

萨特认为，人是被"抛入"这个世界的，没有先天规定好的本质。人首先存在，然后通过自己的选择去定义自己是什么。这就是"存在先于本质"。

正因为没有既定的剧本，人是绝对自由的。但这种自由并不轻松——它意味着我们要为自己的每一个选择负全部责任，无法推诿给命运、他人或环境。萨特把这种处境称为"人被判处自由"。

# 自欺

当一个人面对自由的重负感到眩晕时，常常会选择逃避，假装自己"别无选择"。比如说"我就是这样的人""现实就是这样，我没办法"。萨特把这种自我欺骗称为"自欺"（bad faith）。

自欺的本质，是把自己当成一个被动的物，而否认自己作为自由主体的责任。诚实地生活，意味着承认：此刻的处境或许不是我选的，但如何回应它，永远是我的选择。

# 焦虑与本真

面对无限的选择可能，人会产生焦虑。这种焦虑不是病，而是自由的自然回响——它提醒我们，此刻正站在一个真正属于自己的抉择面前。

本真地活着，不是消除焦虑，而是带着焦虑仍然做出选择，并承担它。逃避焦虑的人把人生交给了"常人"（das Man）的平均标准；本真的人则在清醒中为自己负责。

# 克尔凯郭尔：焦虑是自由的眩晕

克尔凯郭尔把焦虑描述为"自由的眩晕"：人站在可能性之前，像站在崖边往下看——不是怕坠落，而是怕自己随时可能跳。焦虑因此不是病，而是人区别于动物的标志：石头不会焦虑，因为它没有选择。

他同时区分了人群中的"公众"与单个的人。公众是一层抽象的保护壳：躲在里面，任何决定都"不是我的决定"。存在主义的起点，是从公众里认领回那个必须自己跳的单数的人。

# 海德格尔：向死而生与常人

海德格尔用"常人"（das Man）指那种无人负责的平均状态："大家都这样""到时候就知道了"。沉入常人很舒适，代价是把生活的答案权外包给匿名的大多数。

他给出的矫正不是悲观，而是清醒：死亡不是遥远的新闻，而是每个人最私己的可能性。直面它，人反而从"总有下次"的拖延里醒来，开始以有限者的身份排序什么是真正要紧的。向死而生，是把deadline还给人生。

# 萨特续篇：他人、处境与介入

"他人即地狱"常被误读为厌恶人类。它的本义是：他人的目光会把我凝固成一个物件——在别人的评判里，我成了"某种东西"。地狱不是有他人，而是只活在他人眼光里、不再自选。

萨特反对"处境决定论"：处境真实存在且不均等，但同一处境中仍存在不同回应。自由从不免除条件，它只在条件与回应之间的那段空隙里发生。晚年他强调"介入"——作家与知识分子不能假装中立，每一次沉默也是选择。

# 波伏娃：处境中的自由

波伏娃把存在主义推进一步：自由从来不在真空里发牌。性别、阶级、身体构成处境，有些处境系统性地把"选择"变难——例如被规训成"天生该照顾人"的角色。承认这一点，不是取消自由，而是看清自由的真实成本结构。

由此她给出一个更诚实的标准：不问"你有没有选择"（答案永远是有），而问"在这个处境里，选择各自要付什么代价，谁付得起"。同情与要求由此并存。

# 加缪续篇：不做多神，也不做虚无者

加缪拒绝两件现成的外衣：许诺终极意义的大叙事，以及"反正都没意义"的虚无。两者其实是同一种懒惰——都想一次性了结追问。

他留下的立场可操作为：在没有终极裁判的世界里，人靠清楚的理由、可数的行动与对他人有限性的尊重，自己给自己记账。意义不是被找到的存款，是被活出来的流水。

# 自由的日常语法

存在主义落到一天的生活里，有几条语法：把"我不得不"改写成"我选择，因为我在乎另一件事"；把"等想清楚了再做"改写成"先做一件可逆的小事，让信息进来自动清楚"；把"他把我逼成这样"改写成"他做了什么，我回应了什么"——两笔账分开记，不混成一笔宿命。

这些改写不是话术。它们是同一件事的三次练习：把决定权从模糊处领回眼前。
