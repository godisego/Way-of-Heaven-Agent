# 阅读说明

本文选取《论语》中常用于处世、判断与自我修养的章节，原文属公版古籍，按通行分篇标注。解读是原创整理，重点在把两千多年前的对话翻译成今天可执行的行事参照，不做成心灵鸡汤，也不做字面考据。

《论语》的"君子"不是身份，是一种可练习的行为集合。读法上建议每章只取一个动作，落地一周再换下一条。

# 学而：学与习是两件事

"学而时习之，不亦说乎？有朋自远方来，不亦乐乎？人不知而不愠，不亦君子乎？"

三个层次：学是输入，习是反复操练（"习"字本义是雏鸟练飞），悦是从练习里长出来的。最后一句最难——不被看见而不恼火，是不把自我价值外包给即时反馈。做内容、做产品、做手艺的人，这三句是完整的心理建设。

# 为政：先行与不比

"子贡问君子。子曰：先行其言而后从之。"

"君子周而不比，小人比而不周。"

先做后说，说的时候已经有事实背书。周与比的区别：周是以原则团结人，圈子对事开放；比是以利害勾连人，圈子对人站队。判断一个团队，看它怎么对待"说真话的少数"就够了。

# 里仁：见贤思齐的距离感

"见贤思齐焉，见不贤而内自省也。"

"君子喻于义，小人喻于利。"

两面镜子：见贤不嫉妒，拿来对照自己缺什么；见不贤不鄙夷，先查自己身上同款毛病。义利的分辨不在事大事小，在选择时你摆上桌的第一个理由是什么——是"该不该"，还是"划不划算"。

# 述而：不怨天，不尤人

"三人行，必有我师焉。择其善者而从之，其不善者而改之。"

"不怨天，不尤人，下学而上达。"

任何人身上都能拆出两样东西：可学的与可戒的，这个拆解习惯比遇到什么人更重要。"不怨天不尤人"不是不分析外因，而是不让归因停在外因——最后一步必须回到"我能改的那部分"。

# 泰伯与子罕：托孤寄命的分量

"曾子曰：可以托六尺之孤，可以寄百里之命，临大节而不可夺也。君子人与？君子人也。"

"三军可夺帅也，匹夫不可夺志也。"

衡量一个人靠不靠得住，看两点：大事上撑不撑得住（大节不可夺），平时改不改口（志不可夺）。帅位可以被夺走，但一个人对自己要什么的清醒，别人拿不走——前提是他真的想清楚过。

# 颜渊：己所不欲，勿施于人

"仲弓问仁。子曰：出门如见大宾，使民如承大祭。己所不欲，勿施于人。在邦无怨，在家无怨。"

"君子敬而无失，与人恭而有礼，四海之内皆兄弟也。"

"己所不欲勿施于人"是所有协作伦理的最小内核，推己及人是它的正面，"出门如见大宾"是它的日常化——把每一次对外出席当成正式场合，郑重但不僵硬。无怨不是要求别人给你公道，是自己先不做将来会被抱怨的事。

# 卫灵公：求诸己与小不忍

"君子求诸己，小人求诸人。"

"小不忍则乱大谋。"

"巧言乱德，小不忍乱大谋。"

出了问题先查自己那半张网，这是成本最低的成长方式。"忍"不是忍气吞声，而是忍住即时反应——不立刻回怼、不立刻拍板、不立刻发那条消息。忍的对象是自己的第一冲动，不是正当的边界。

# 季氏与阳货：三种损耗

"益者三友，损者三友。友直，友谅，友多闻，益矣。友便辟，友善柔，友便佞，损矣。"

"鄙夫可与事君也哉！其未得之也，患得之；既得之，患失之。苟患失之，无所不至矣。"

交友的三益三损给出了一张名片审核表：直（敢说逆耳话）、谅（守信）、多闻（有真材料）；反之是表演型姿态、讨好型柔顺、夸夸其谈。"患得患失"四个字则刻画了焦虑型掌权者的画像——怕失去的人什么都做得出来，识别并远离这种决策环境。

# 尧曰：宽、信、敏、公

"宽则得众，信则民任焉，敏则有功，公则说。"

《论语》以四条管理心法收尾：宽容得人心，守信立信任，勤敏出成果，公平服众人。它可以原样印在任何团队的墙上——两千多年过去，这四件事依然稀缺，依然有效。
